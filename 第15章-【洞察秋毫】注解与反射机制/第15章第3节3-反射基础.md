## 3.1 什么是反射

Java反射（Reflection）允许程序在<font color="red">**运行时**</font>（Runtime）去"检查"和"操作"它自身的信息，尤其是类的信息。

核心一句话：反射让你在看不到源代码的情况下，仅仅通过一个类的全限定名（字符串），就能了解这个类的所有内部结构，并能创建它的对象、调用它的方法、访问它的字段。

```
    正常方式：你知道类名 → import → new → 使用
    反射方式：你只有字符串 → Class.forName → 动态创建 → 使用
```

反射的真正威力在于它的<font color="red">**动态性**</font>。它让代码变得非常灵活，主要用在一些"框架"和"工具"中。

经典场景：
- <font color="red">**IDE的智能提示**</font>：输入一个点"."，IDE能自动弹出这个对象的所有方法和属性
- <font color="red">**Spring框架**</font>：在配置文件里写上类的名字，Spring容器在运行时就能通过反射来创建这些对象
- <font color="red">**JUnit**</font>：扫描测试类中的`@Test`注解并执行

## 3.2 Class对象

要很好地使用反射，必须了解Class对象这个概念。

小写的`class`是一个关键字用来定义一个类，而大写的`Class`本身就是一个类。

```java
public final class Class<T> implements java.io.Serializable, ... {
    // Class是一个泛型类
}
```

Java使用元类Class来保存普通类的相关数据。涉及4个概念：

```
    普通类（如Car）         → 汽车的设计图纸
    普通对象（new Car())    → 根据图纸生产出来的具体汽车
    Class类                → 图纸的规范（所有图纸的模板）
    Class对象（Car.class）  → 档案馆里某款汽车的具体图纸档案
```

你可以永远这样简单地记忆：
- 你想操作业务数据，就去找<font color="red">**普通对象**</font>
- 你想在运行时分析程序自身的结构，就去找对应类的<font color="red">**Class对象**</font>

## 3.3 获取Class对象

主要有三种方式：

<font color="red">**ClassName.class**</font>：字面量方式，最直接。

```java
Class<String> stringClass = String.class;
```

<font color="red">**object.getClass()**</font>：通过对象的实例方法获取。

```java
String s = "Hello";
Class<? extends String> aClass = s.getClass();
```

<font color="red">**Class.forName("fully.qualified.ClassName")**</font>：通过类的全限定名动态加载。

```java
Class<?> aClass = Class.forName("java.lang.String");
```

对于初学者，最重要的是记住第三种`Class.forName()`，因为它最能体现反射的动态性——类的名字可以来自配置文件、用户输入、网络传输等任何地方。

## 3.4 反射的核心操作

拿到Class对象后，就可以"为所欲为"了。反射主要提供三大类操作。

```java
package com.example;
class Person {
    private String name;
    private int age;
    public void setName(String n) { this.name = n; }
    public String getName() { return this.name; }
}
```

### 操作一：创建对象

正常情况下使用`new`：
```java
Person p = new Person();
```

反射方式：
```java
// 1. 获取Class对象
Class<?> clazz = Class.forName("com.example.Person");

// 2. 获取构造方法 Constructor（无参构造）
Constructor<?> constructor = clazz.getDeclaredConstructor();

// 3. 使用 Constructor 创建对象
Object personInstance = constructor.newInstance();

System.out.println(personInstance.getClass().getName()); 
// 输出: com.example.Person
```

`newInstance()`方法相当于调用了`new Person()`。

### 操作二：调用方法

正常情况下：
```java
p.setName("Lily");
```

反射方式：
```java
// 1. 获取 Method 对象（参数：方法名, 方法的参数类型）
Method setNameMethod = clazz.getMethod("setName", String.class);

// 2. 调用方法（参数：哪个对象调用, 传入的具体参数值）
setNameMethod.invoke(personInstance, "Lily");

// 验证
Method getNameMethod = clazz.getMethod("getName");
Object result = getNameMethod.invoke(personInstance);
System.out.println(result); // 输出: Lily
```

### 操作三：操作字段

正常情况下：
```java
p.age = 30; // 仅当age是public时
```

反射方式：
```java
// 1. 获取 Field 对象
Field ageField = clazz.getDeclaredField("age");

// 对于非public的字段，需要先设置可访问性
ageField.setAccessible(true); // 这是一把"钥匙"，打开private的访问限制

// 2. 设置字段值
ageField.set(personInstance, 30);

// 3. 获取字段值
Object ageValue = ageField.get(personInstance);
System.out.println(ageValue); // 输出: 30
```

可以看到，反射非常强大。只要你有Class对象，你可以灵活地做各种操作，甚至可以直接操作私有的成员变量。

## 3.5 反射 vs 正常编程

| 特性 | 正常编程 | 反射 |
|------|----------|------|
| 时间 | 编译时 | 运行时 |
| 确定性 | 知道具体的类和方法 | 通过字符串名字操作 |
| 灵活性 | 低 | 极高 |
| 性能 | 高 | 较低 |
| 主要用途 | 编写业务逻辑 | 构建框架、工具、动态代理 |

## 3.6 反射的优缺点

<font color="red">**优点**</font>：
- 灵活性极高，实现了动态创建和操作对象，是很多复杂框架的基础
- 通用性强，可以编写出非常通用的代码，与具体的类解耦

<font color="red">**缺点**</font>：
- 性能较低，反射操作比直接的Java代码慢很多（要做额外的检查和处理）
- 安全性问题：反射可以绕过权限检查，能操作私有成员，破坏了封装性
- 代码复杂性高：反射代码比较繁琐，可读性差，也更难调试

反射在常规的业务编程里并不常用。如果你的普通业务代码能用正常方式实现，就尽量不要用反射。反射更多的是为那些框架开发者准备的"屠龙技"。
