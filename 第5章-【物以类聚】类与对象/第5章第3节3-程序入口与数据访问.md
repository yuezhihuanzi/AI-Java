## 3.1 Java 程序的入口点

下面是一段 Java 代码，它没有语法错误，但并不会被执行：

```java
class Cat {
    String name; 
    int age;     

    void meow(){
      System.out.println(name+"正在喵喵叫");
    }
}
```

为什么不会被执行？因为上述代码是<font color="orange">声明性语句</font>，不会立即执行。一段程序想要执行，必须有一个「<font color="blue">入口点</font>」，这有点像「多米诺」骨牌的第一张牌——只要触发放倒第一张，就会启动整个骨牌开始坍塌。

Java 是强制面向对象的，任何代码都必须放在类中。但类是声明性语句，不能被直接执行。那入口点在哪？

Java 给出了一个解决方案：用一个特殊的入口方法，来作为多米诺骨牌的启动点：

```java
class Main {
    public static void main(String[] args) {
        System.out.println("直接执行程序,我可以被打印出来");
    }
}
```

入口方法有如下特点：

- 入口方法名必须为 `main`
- 入口方法前必须有 `static` 关键字
- 入口方法的返回类型必须是 `void`
- 入口方法形参必须为 `String[] args`
- 入口方法必须有 `public` 修饰符

以上五个要素缺一不可，签名固定为 <font color="red">**`public static void main(String[] args)`**</font>。

## 3.2 启动类

虽然入口方法放在哪个类中都可以执行，但 Java 习惯将它放在名为 `Main` 的类中：

```java
// 位于Main.java文件中
class Main {
    public static void main(String[] args) {
        System.out.println("程序启动");
        Cat cat = new Cat();
        cat.meow();
    }
}

class Cat {
    void meow(){
      System.out.println("正在喵喵叫");
    }
}
```

> **注意**  
> 上述两个 Java 类可以位于同一个文件中。Java 规定，<font color="red">**每个 `.java` 文件只允许存在一个 `public` 的类**</font>，但可以有多个非 `public` 的类。

这段代码演示了几乎所有 Java 程序的启动模型：<font color="blue">启动类</font>负责启动，在入口方法中编写业务代码——实例化 `Cat` 类，调用 `cat` 对象的 `meow` 方法。

从本章开始，我们基本具备了执行一段完整 Java 程序的能力，建议同学们在后续章节里多动手写代码。

## 3.3 类的封闭性

面向对象有三大特性：封装性、继承性、抽象性。目前讲解这三大特性还为时过早，但我们现在有必要讲解一下类的<font color="blue">封闭性</font>——它是「封装性」的基础。

所谓「封闭性」，指的是类里的成员变量和方法，应该尽可能地与类的外部隔离开，不轻易地被外界影响。

类之所以希望自身被封闭起来，可以用以下类比：一个正在准备高考的同学，更倾向于在一个封闭的空间里安静学习，排除一切干扰。

类也是一样，只有保持封闭性，它内部的数据才是「可控的」。假设：

```java
class BankAccount {
   float totalMoney = 1000;
}
```

假如上述的类代表了银行账号，你有存款 1000 元。如果能随意从类的外部修改这个金额——比如有人把你的存款从 1000 元改为 10 元——这显然不合适。

让类保持封闭性，不让外界随意修改对象内部的数据，可以在一定程度上减少混乱，保证对象内部数据的「安全性」。

当然，数据不可能一直不变。猫出生是 0 岁，但随着年龄增长需要修改。所以「避免修改」不是不能修改，而是：<font color="red">**尽量避免从类的外部直接修改类内部的数据。如果一定要修改，最佳做法是让类自己修改自己的数据**</font>。

由类自己修改数据，可以验证值是否合法（如年龄不能为负数）。但如果允许外部直接修改，谁能保证不会设置异常值呢？

<font color="red">**「自己是自己的第一责任人」**</font>——类的数据只由自己改变，同时类也要为自己改变的数值负责。

此外，类的封闭性还有一层含义：类也不希望数据被外界随意**读取**。每个人都有一些隐私，类也如此。原则上，能隐藏的数据就尽量隐藏。

## 3.4 访问成员变量

成员变量的访问使用 `.` 点操作符：

```text
对象名.成员变量
```

`.` 点操作符常用于访问某个对象中的成员变量和方法，可以理解为中文「的」的意思：

```java
class Cat {
   int age;
   String name;
}

Cat cat = new Cat();
cat.age = 3;        // 将cat对象"的"age赋值为3
cat.name = "大壮";  // 将cat对象"的"name赋值为"大壮"
```

点操作符可以级联访问：

```java
cat.person.name = "莉莉";  // 猫的主人的名字是莉莉
```

但通常不会级联太深，过多的级联不是好的设计方案。

除了成员变量，对象的方法也可以通过点操作符来访问：

```java
Cat cat = new Cat();
cat.meow();  // 调用cat对象的meow方法
```

最后，注意一种常见错误：

```java
Cat.age = 3;    // 错误!
Cat.meow();     // 错误!
```

这是错误的，因为 `Cat` 没有实例化。通过类名直接访问成员变量、调用方法，在 Java 中是不允许的。<font color="orange">必须先实例化对象，再通过对象访问。</font>
