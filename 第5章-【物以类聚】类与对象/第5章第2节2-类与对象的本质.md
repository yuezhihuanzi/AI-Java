## 2.1 什么是类

在经典的面向对象编程语言中，「类」与「对象」是两个至关重要的概念。要真正理解面向对象编程，首先必须厘清这两者的含义及其关系。

那么，「类」究竟是什么？

就我个人而言，会立刻联想到「类别」和「品类」。《辞海》将「类」诠释为「种类」，即相似事物的综合。这与《周易·繫辞上》中「方以类聚，物以群分」的智慧不谋而合。

猫和狗为什么不是同一类动物？答案很简单：

- 猫能抓老鼠，但狗不会（行为上有差别）
- 猫是喵喵叫，但狗是汪汪叫（行为上有差别）
- 猫通常鼻子小巧，而狗鼻子通常更大一些（特征上有差别）

所以我们划分不同的「种类」，依据就是<font color="red">**特征和行为**</font>。

计算机里的类也是一样的，它必须要记录某个种类的特征和行为：

![类的特征与行为模板示意](https://www.logamee.com/uploads/md_resources/course77/chapter272/20260829_064801/1-%E7%B1%BB%E4%B8%8E%E5%AF%B9%E8%B1%A1%E7%9A%84%E6%9C%AC%E8%B4%A8/image.png)

类很简单，它就是编程语言用来记录现实世界事物的<font color="red">**特征和行为的模板**</font>。

## 2.2 对于类常见的错误理解

很多初学者对类都有一个理解误区：<font color="orange">类既不是用来表达具体的事物，也不是用来表示某个分类的全体集合。</font>类只用来描述某个事物的「特征和行为」。

## 2.3 抽象 vs 具体

「抽象」这个概念对编程来说极其重要。不理解抽象，是写不出高度概括性与极强通用性程序的。

在编程世界里，抽象和具体是一对反义词。我们先给出一个结论：<font color="red">**抽象是比具体更高一层的机制**</font>。

「具体」很容易理解，你在现实世界里看到的各种物体，一只猫、一辆车均是「具体」。

那「抽象」是什么？我们用「西红柿炒鸡蛋」来说明：

![西红柿炒鸡蛋示例](https://www.logamee.com/uploads/md_resources/course77/chapter272/20260829_064801/1-%E7%B1%BB%E4%B8%8E%E5%AF%B9%E8%B1%A1%E7%9A%84%E6%9C%AC%E8%B4%A8/image-3.png)

将炒菜这个流程单独抽出来，就会形成一个通用的指导规则，这是比具体菜谱更高一个层级的抽象。

![从具体菜谱抽象出通用规则的示意](https://www.logamee.com/uploads/md_resources/course77/chapter272/20260829_064801/1-%E7%B1%BB%E4%B8%8E%E5%AF%B9%E8%B1%A1%E7%9A%84%E6%9C%AC%E8%B4%A8/image-4.png)

在编程里，<font color="blue">抽象</font>其实就是将事物的本质提取出来，形成一套说明或者指导规则。具有很强抽象思维能力的程序员，往往更善于写出通用性更强的程序。

## 2.5 什么是对象

「对象」是根据「类」创建出来的一个个具体的个体：

![类与对象的关系示意](https://www.logamee.com/uploads/md_resources/course77/chapter272/20260829_064801/1-%E7%B1%BB%E4%B8%8E%E5%AF%B9%E8%B1%A1%E7%9A%84%E6%9C%AC%E8%B4%A8/image-6.png)

`Cat` 类是基因蓝图，通过这个基因蓝图可以克隆出一个个具体的猫，这一个个具体的猫就是「对象」。

比如用 `Cat` 类克隆了一只名为「大壮」的加菲猫（对象），又用 `Cat` 类克隆了一只名为「姜磺」的波斯猫（也是一个对象）。

所以<font color="orange">类是抽象的，只是一个模板、规则。而对象是具体的，就是模板创造出来的各种具体个体。</font>

<font color="red">**千万不要将「类」和「对象」的关系理解成「集体」和「个人」、「复数」和「单数」的关系。**</font>它们其实是<font color="red">**模具与实物**</font>的关系。

## 2.6 类的实例化

「类」这个蓝图可以创造出独特的对象，我们把「创造独特对象」的过程称为「<font color="blue">实例化</font>」。

Java 通过关键字 <font color="blue">`new`</font> 来实例化一个对象：

```java
// 一个最简单的Cat类(空类)
class Cat {
    // 可以没有任何成员变量和成员方法
}

// 理论上可以创建(实例化)无数个对象
Cat cat1 = new Cat();
Cat cat2 = new Cat();
Cat cat3 = new Cat();
```

`Cat` 类的实例化类似于定义一个变量：

```java
Cat cat3 = new Cat();
// Cat是类型,cat3是变量名,new Cat()是实例化对象
```

同学们可能不好理解 `Cat` 也是一个类型。目前我们已经知道有 8 种基本类型，但世界上的事物太多了，Java 不可能预先将所有的「类型」都内置。这就需要程序员自己定义类型——`Person` 类和 `Cat` 类就是我们定义的「自定义类型」，它们和 `int` 等基本类型一样可以定义变量。

`new` 关键字可以实例化一个对象，语法为：

```java
new Cat()  // ()不能省略
```

`new` 英文释义为「新的」。通过模板创造一个「新的」对象，所以用 `new` 这个关键字，很传神。

## 2.7 构造函数

对象的初始特征非常重要。假如我们需要实例化两个猫的对象，它们应该具有不同的特征值——世界上找不到两片完全一样的树叶。

<font color="blue">构造函数</font>是类的「特殊」方法，用于在对象实例化时初始化对象的特征：

```java
class Cat {
    // 成员变量
    String name;  // 名字
    int age;      // 年龄

    // 构造函数 - 用于初始化对象
    Cat(String catName, int catAge) {
        name = catName;
        age = catAge;
    }
    
    // 成员方法:喵喵叫
    void meow() {
        System.out.println("喵喵喵!");
    }
}
```

构造函数和普通方法类似，但也有差异：

- 构造函数名必须与类名相同
- 没有返回类型（连 `void` 都没有）

在实例化时，将特征数值传入到对象中：

```java
Cat cat1 = new Cat("姜磺", 2);
Cat cat2 = new Cat("大壮", 3);
```

这和方法调用传入参数的形式一模一样——因为通过 `new` 关键字实例化类时，实际上会调用类的构造函数，而构造函数本身就是一个特殊的方法。

## 2.8 无参与有参构造函数

构造函数分为有参数的构造函数和无参数的构造函数。

<font color="red">**无参构造函数可以省略，当类没有定义任何构造函数时，Java 会为其生成一个默认的无参构造函数。**</font>

<font color="red">**如果类显式定义了有参构造函数，则 Java 不会自动生成无参构造函数。**</font>

```java
class Cat {
    String name;
    int age;
    
    // 有参构造函数
    Cat(String catName, int catAge) {
        name = catName;
        age = catAge;
    }
}

Cat cat1 = new Cat("姜磺", 1); // 正确
Cat cat2 = new Cat();          // 错误,类没有无参构造函数
```

如果既要有参，又要无参，可以显式定义两种构造函数。此外，一个类可以有多个有参构造函数同时存在，只要它们的参数列表不同即可。
