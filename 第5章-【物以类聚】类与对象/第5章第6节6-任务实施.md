## 6.2 [P] 预测——对象之间会不会互相影响

看这段代码，先不要运行：

```java
class Enemy {
    String name;
    int hp;

    Enemy(String name, int hp) {
        this.name = name;
        this.hp = hp;
    }

    void showInfo() {
        System.out.println(name + " HP：" + hp);
    }
}

public class EnemyDemo {
    public static void main(String[] args) {
        Enemy a = new Enemy("影子怪", 30);
        Enemy b = new Enemy("暗影狼", 45);
        a.showInfo();
        b.showInfo();
    }
}
```

预测：

1. `a.showInfo()` 会输出什么？
2. `b.showInfo()` 会输出什么？
3. 修改 `a.hp` 会影响 `b.hp` 吗？

## 6.3 [R] 运行——验证预测

运行上面的代码：

```text

暗影狼 HP：45
```

两个对象各自拥有独立的 `name` 和 `hp`。<font color="red">修改 `a.hp` 不会影响 `b.hp`。</font>
