## 5.1 任务要求

- `Player` 字段：名字、等级、HP、MP、攻击、防御、金币

## 5.2 [I] 研究——分析最小数据档案

先看 `Player` 的基础字段：

```java
class Player {
    final int MAX_LEVEL = 100;

    String name;
    int level;
}
```

拆解：

| 组成部分 | 作用 | 示例 |
|---------|------|------|
| 常量 | 固定不变的值 | `final int MAX_LEVEL = 100;` |
| 字段 | 可变化的数据 | `String name;` |
| 数据类型 | 决定数据范围 | `int`、`String` |
