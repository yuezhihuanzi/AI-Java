## 3.1 常量的定义与使用

可以使用下述语法定义常量：

```java
// 基本数据类型常量
final int MAX_USERS = 100;
// 声明常量时就为其赋值3.1415926是一个良好的习惯
final double PI = 3.1415926;
final char GRADE = 'A';
```

常量定义（也可以被称为常量声明）有以下几点需要注意：

- 开头使用<font color="red">**final 关键字**</font>修饰，如果没有 final 关键字，那么定义的是一个「变量」而不是「常量」
- 常量的名称通常<font color="red">**全部大写**</font>，多个单词之间用 `_` 分隔
- 常量通常在声明时就需要为其赋值。在一些特殊情况下，声明时也可以不为其赋值，但并不建议这样做
- 常量一旦声明后就<font color="red">**不能再被改变**</font>

```java
// 正确：基本数据类型常量
final int MAX_USERS = 100;
// 错误：常量一旦被赋值后，不能再被改变
MAX_USERS = 30; // 这行代码会报错
```

## 3.2 误区澄清：常量由项目决定，而非客观世界

很多初学者会认为：只有像光速、圆周率这种在物理世界里永恒不变的量才应该定义为常量。<font color="orange">这个理解是错的。</font>

<font color="red">**一个量是否应该定义为常量，取决于你的项目需要，而不是它在现实世界中是否会变化。**</font>

举例来说：

- **年龄**——它随着岁月流逝不断增长。但如果你的系统只研究 20 岁的年轻人，所有逻辑都围绕「20 岁」这个固定值展开，那么 `AGE = 20` 完全可以定义为常量。至于现实里的人会不会变老，和你的程序无关。
- **光速**——它在物理世界里恒定不变。但如果你做一个科学实验，想模拟「假如光速改变了会发生什么」，那么光速在你的程序里就应该是一个变量，方便你调整它来观察效果。

结论很简单：<font color="red">**常量不是对客观世界的描述，而是你对程序的一种设计决策。**</font> 它只取决于——在你的项目的上下文中，这个值是否被设计为固定不变。

## 3.3 字符串类型

之前我们聊到过，单个字符可以用 char 类型来表示。但是如果是多个字符应该如何表示？比如一部小说、一段演讲稿、一首宋词，它们涉及到多个字符组合在一起。

这种情况下需要用「字符串」这种数据类型。字符串可以用<font color="red">一对英文双引号</font>来定义：

```java
// 字符串示例
String greeting = "Hello, World!";
String name = "Lily";
String empty = ""; // 空字符串
String letter = "A"; // 一个字符也可以定义成字符串
```

这里特别强调，<font color="red">**字符串不属于 Java 的 8 种基本类型**</font>，它们在存储原理和运算机制上有诸多不同。字符串实际上是一个对象，属于「<font color="blue">引用类型</font>」。
