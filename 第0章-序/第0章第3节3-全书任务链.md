## 3.1 本书主线

本书直接布置任务，不用角色和场景包装。每章开头直接给出任务目标、已有基础、需要实现和完成标准。你完成一章后，下一章会继续使用这些成果。<font color="red">任务不是孤立练习，而是在同一个程序里逐步增加功能。</font>

---

## 3.2 16 章任务

1. **用类的思维描述世界**：先完成猫类模型练习，再为最终程序的 `Player`、`Area`、`Enemy` 设计字段与行为。

2. **创建类的定义**：先定义 `Cat` 类熟悉类结构，再定义 `Player` 类，包含字段和方法骨架。

3. **管理程序中的数据**：为 `Player` 设计数据档案，为名字、等级、HP、MP、攻击、防御、金币等数据选择正确类型，并定义必要的常量。

4. **让程序动起来**：为 `Player` 添加 `showInfo()`、`takeDamage()`、`heal()`、`restoreMp()`、`spendGold()` 方法，并用 `main` 方法创建对象、调用方法验证功能。

5. **创建生物类与对象**：编写 `Enemy` 和 `Area` 类，设计带参构造函数和启动类，创建多个对象并调用方法。

6. **计算战斗伤害**：创建 `Skill` 类，实现伤害计算、战斗结算、胜负判定、金币奖励和完整战斗模拟。

7. **管理字符串与数据引用**：为程序添加信息显示模块，完成档案格式化、战斗日志生成和引用类型比较。

8. **实现条件判断与循环**：为程序添加冒险决策模块，实现区域准入、战斗结果判定、主菜单和菜单循环。

9. **管理冒险者队伍**：用数组管理区域，用 `List` 管理技能，用 `Map` 管理背包物品，完成遍历、查找和显示。

10. **保护核心数据**：将 `Player` 的 `hp`、`mp`、`gold`、`level` 改为 `private`，提供带合法性检查的 getter 和专用修改方法。

11. **复用与扩展代码**：定义父类 `Creature`，让 `Player` 和 `Enemy` 继承共有属性与方法。

12. **识别更多生物类型**：定义 `Character` 抽象类和 `Questable` 接口，让 `Player`、`Enemy`、`Area` 用统一抽象方式协作。

13. **设计通用工具箱**：实现泛型类 `Bag<T>`，用 `Bag<Item>` 管理背包物品，并编写泛型方法和通配符方法。

14. **处理程序中的异常**：定义 `InsufficientGoldException` 和 `AreaLockedException`，用 try-catch、finally 和自定义异常保护交易、区域进入与存档流程。

15. **用注解标记与反射探测**：定义 `@Skill` 注解，用反射扫描技能方法、读取注解属性，并自动生成存档信息。

16. **简化数据处理流程**：用 Lambda、Stream 和 Optional 重构排序、名录查询、技能查找和背包物品处理，减少空指针检查和重复代码。

## 3.3 任务衔接

<font color="blue">前两章</font>先建立类和对象的基础，为后续所有模块提供模型。<font color="blue">第 3 到第 5 章</font>补充数据、行为、构造函数和程序入口，让对象可以真正运行。<font color="blue">第 6 到第 8 章</font>加入战斗计算、信息展示和交互菜单，程序开始形成可操作的主流程。<font color="blue">第 9 到第 12 章</font>扩展数据管理、封装、继承和多态，让程序能够处理更多对象。<font color="blue">最后四章</font>用泛型、异常、反射和函数式编程整理整个系统，让它更健壮、更简洁。

---

## 3.4 完成标准

读完 16 章后，你得到的是<font color="red">一个可以运行的 Java 程序</font>。它至少包含数据档案、战斗计算、信息显示、菜单循环、数据管理、访问控制、生物类型体系、通用容器、异常防护、技能扫描和简化数据处理模块。程序从命令行主菜单进入，可以查看状态、探索区域、进入商店、处理战斗，并为后续扩展存档流程留出接口。

最终程序的冒险者名字由使用者启动时输入，教材中的默认名为「姜磺」。区域是固定关卡，<font color="orange">通关后不能重复刷金币</font>；玩家需要在技能、装备、HP/MP 药水之间做取舍，金币总量负责控制整局平衡。
