## 7.2 [P] 预测——同一个方法调用会产生不同行为吗

```java
abstract class Character {
    String name;

    Character(String name) {
        this.name = name;
    }

    abstract void act();
}

class Player extends Character {
    Player(String name) {
        super(name);
    }

    void act() {
        System.out.println(name + "探索区域");
    }
}

class Main {
    static void executeAction(Character[] characters) {
        for (Character character : characters) {
            character.act();
        }
    }

    public static void main(String[] args) {
        Character hero = new Player("姜磺");
        executeAction(new Character[]{hero});
    }
}
```

预测：
1. 能写 `new Character("姜磺")` 吗？
2. `character.act()` 调用的是哪个实现？

## 7.3 [R] 运行——验证预测

```
姜磺探索区域
```
