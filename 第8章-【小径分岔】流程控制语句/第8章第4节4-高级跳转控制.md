## 4.1 循环标签（Label）

有时候，我们要从内层循环直接结束所有的循环，这种情况可以用循环标签：

```java
outerLoop: // 定义标签
for (int i = 1; i <= 3; i++) {
    // ...
    for (int j = 1; j <= 3; j++) {
        System.out.println("i=" + i + ",j=" + j);
        if (i == 2 && j == 2) {
            break outerLoop; // 跳出标签指定的循环
        }
    }
}
```

在 Java 中，`outerLoop` 是一种标签（label），它用于标识一个循环语句。标签通常用在嵌套循环中，当我们需要从内层循环直接跳出外层循环时，就可以使用带标签的 `break` 或 `continue` 语句。

**上述代码结果**：

```
i=1,j=1
i=1,j=2
i=1,j=3
i=2,j=1
i=2,j=2
```

这里 `break` 和 `outerLoop` 连用的作用在于，当满足 if 条件时（`i==2 && j==2`），break 不仅结束掉了内层循环，它还结束掉了外层循环。

**重要注意事项**：

`outerLoop` 的作用并不是结束所有的循环，而是结束 `outerLoop` 所在位置的循环：

```java
for (int i = 1; i <= 3; i++) {
    outerLoop: // 标签位置
    for (int j = 1; j <= 3; j++) {
        for (int k = 1; k <= 3; k++) {
            if (j == 2 && k == 2) {
                break outerLoop; // 跳出标签指定的循环
            }
        }
    }
}
```

比如上述这段代码，当 `break outerLoop` 执行时，<font color="orange">**并不会跳出所有的三层循环**</font>，而是会结束掉 `outerLoop` 以下的所有循环，但是最外层的变量 `i` 的循环还是会执行。

**标签命名规则**：

- 标签并不一定要起名为 `outerLoop`，实际上任意合法的名字都可以用于标签名，甚至是 `a`、`b`、`c` 这种也可以
- 但通常我们建议名字还是要有意义，比如 `outer`、`outerLoop` 等

## 4.2 return 语句

**作用**：从方法中返回结果并终止执行

**示例 1：带返回值的 return**

```java
public int calculate(int a, int b) {
    if (b == 0) {
        return -1; // 提前返回-1
    }
    // 如果b==0，下面代码不会执行
    return a / b;
}
```

上述代码只要 `b==0`，那么就会返回 -1，并终止后续代码的执行。

**示例 2：无返回值的 return**

```java
public void calculate(boolean isTrue) {
    if (isTrue) {
        // 如果isTrue==true，则直接结束当前方法
        return;
    }
    // 否则会执行打印
    System.out.println("Hello World");
}
```

在方法中提前使用 return 终止当前方法的后续流程是一种非常常见的写法。

## 4.3 return 提前结束循环

巧妙使用 return 还可以提前结束循环：

```java
public void showSample() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            System.out.println("i=" + i + ",j=" + j);
            if (i == 2 && j == 2) {
                return;         
            }
        }
    }
}
```

上述方法中，当满足 if 条件时，执行 return 语句会<font color="red">**直接结束方法**</font>，从而间接实现结束所有循环。

## 4.4 break 标签 vs return 对比

| 特性 | break 标签 | return |
|------|-----------|--------|
| 作用范围 | 结束标签指定的循环 | 结束整个方法 |
| 后续代码 | 方法内循环后的代码继续执行 | 方法内所有后续代码都不执行 |
| 使用场景 | 需要退出嵌套循环但继续方法执行 | 需要完全终止方法 |
| 返回值 | 不返回任何值 | 可以返回值（非 void 方法） |

```java
// break标签：退出循环，但方法继续
public void testBreakLabel() {
    outerLoop:
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (i == 2 && j == 2) {
                break outerLoop; // 只结束循环
            }
        }
    }
    System.out.println("循环结束，但方法继续执行"); // 会执行
}

// return：完全终止方法
public void testReturn() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (i == 2 && j == 2) {
                return; // 结束整个方法
            }
        }
    }
    System.out.println("不会执行"); // 不会执行
}
```

## 4.5 三种跳出循环的方式总结

Java 提供了三种跳出循环的方式，各有适用场景：

**1. break：跳出当前循环**

```java
for (int i = 1; i <= 10; i++) {
    if (i == 5) break; // 只跳出当前这一层循环
}
```

适用场景：单层循环或只需跳出最内层循环

**2. break 标签：跳出指定循环**

```java
outerLoop:
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (i == 2 && j == 2) break outerLoop; // 跳出outerLoop标记的循环
    }
}
```

适用场景：嵌套循环中需要跳出外层循环

**3. return：终止方法间接结束循环**

```java
public void findTarget() {
    for (int i = 1; i <= 3; i++) {
        for (int j = 1; j <= 3; j++) {
            if (i == 2 && j == 2) return; // 结束整个方法
        }
    }
}
```

适用场景：找到目标后无需继续执行方法的任何代码
