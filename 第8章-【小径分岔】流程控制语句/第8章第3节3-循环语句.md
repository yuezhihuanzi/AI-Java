## 3.1 for 循环

循环是任何主流编程语言里都必不可少的一种逻辑，因为计算机的本质就是在周而复始地通过不断的循环来解决复杂的问题。

**基本结构**：

```java
for (初始化; 条件; 迭代) {
    // 循环体
}
```

**示例**：

```java
// 打印 1-5
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}
```

**循环的执行步骤**：

1. 将 `i` 的初始值设置为 1（初始化）
2. 判断 `i <= 5` 是否成立（条件判断）
3. 如果成立，执行循环体里的代码 `System.out.println(i)`
4. 执行完毕后进行迭代 `i++`，迭代后 `i=2`
5. 继续判断 `i <= 5` 是否成立
6. 由于 `i=2`，所以成立，继续执行循环体里的代码
7. 继续迭代，`i=3`
8. ……重复步骤 2 到 7
9. 迭代后 `i=6`
10. 继续判断 `i <= 5` 是否成立，此时不成立
11. 结束循环

循环非常重要，建议在 IDE 里多练习几次，理解它的执行流程。

## 3.2 多层 for 循环

for 循环的内部还可以嵌套 for 循环，如果你愿意可以无限制地嵌套 for 循环。我们以两层 for 循环为例：

```java
// 外层循环控制行数
for (int i = 1; i <= 3; i++) {
    // 内层循环控制每行打印的内容
    for (int j = 1; j <= 3; j++) {
        System.out.print("(" + i + "," + j + ") ");
    }
    // 每行结束后换行
    System.out.println();
}
```

**输出结果**：

```
(1,1) (1,2) (1,3) 
(2,1) (2,2) (2,3) 
(3,1) (3,2) (3,3) 
```

多层嵌套循环并不太好理解，我们尝试用简单的变量改变来说明循环流程：

```
i=1, j=1;
i=1, j=2;
i=1, j=3;  // 此时内层循环结束
i=2, j=1;
i=2, j=2;
i=2, j=3;  // 此时内层循环结束
i=3, j=1;
i=3, j=2;
i=3, j=3;  // 此时内层循环结束，同时外层循环也结束
```

**关键规则**：

- 外层循环执行 1 次，内层循环执行完整的一轮（从初始值到条件不成立）
- 内层循环完全结束后，外层循环才进行下一次迭代
- 可以理解为：外层循环控制「行数」，内层循环控制「每行的内容」

> **最佳实践**  
> 多层嵌套循环并不是一个好的代码写法，应该尽量避免。通常最多不应该超过 3 层循环，过多的嵌套循环会让代码变得无法阅读。

## 3.3 while 循环

while 是另一种可以实现循环的语句：

**基本结构**：

```java
while (condition) {
    // 循环体
}
```

while 每一次都会判断 `condition` 的结果，只要 `condition` 计算为 `true`，就会执行循环体内的语句：

```java
int count = 1;
while (count <= 5) {
    System.out.println(count);
    count++;
}
```

**使用 while 循环的注意事项**：

使用 while 循环，务必要注意<font color="red">**必须在循环体内改变条件的值**</font>，否则将出现「<font color="blue">死循环</font>」，即代码会一直执行循环不会终止。在大多数场景下，这显然是不能接受的。

比如上述代码中，必须有 `count++`，否则 `count` 将一直等于 1，这就会让 `count <= 5` 永远成立，从而导致循环无法终止。

> **警告**  
> 绝大多数情况「死循环」都会导致非常严重的程序错误，甚至会造成「内存泄漏」。程序员必须对无限循环非常敏感。  
>  
> 但这里要说明的是，并不是所有的无限循环都是错误的。在某些场景下，比如为了持续监听计算机端口，可能会使用无限循环。

## 3.4 while vs for

while 和 for 都可以实现循环，但它们的使用场景有所不同：

- **for 循环**：适合已知循环次数的场景，如「循环 10 次」、「遍历数组」
- **while 循环**：适合未知循环次数但有明确结束条件的场景，如「读取文件直到末尾」、「等待用户输入」

```java
// for循环：已知循环5次
for (int i = 1; i <= 5; i++) {
    System.out.println(i);
}

// while循环：未知循环次数，但有结束条件
int count = 1;
while (count <= 5) {
    System.out.println(count);
    count++;
}
```

两者在功能上是等价的，可以根据代码的可读性选择使用哪种。

## 3.5 do-while 循环

do-while 类似于 while 循环，但有一些区别。

**基本结构**：

```java
do {
    // 循环体（至少执行一次）
} while (condition);
```

**执行特点**：

do-while 无论如何（无视条件）都会执行一次循环体内部代码。在执行完这一次后，再去判断 `condition` 条件，决定是否还继续执行。

但 while 语句是<font color="orange">**先判断条件**</font>再决定是否执行循环体内部的代码。

**示例**：

```java
int x = 10;
do {
    System.out.println(x); // 输出 10
    x++;
} while (x < 5); // 条件不成立仍执行一次
```

虽然 `x=10`，不满足条件（`x < 5`），但依然会执行一次循环体里的代码。

**while vs do-while**：

```java
// while：先判断，可能一次都不执行
int a = 10;
while (a < 5) {
    System.out.println(a); // 不会执行
    a++;
}

// do-while：先执行，至少执行一次
int b = 10;
do {
    System.out.println(b); // 输出 10
    b++;
} while (b < 5);
```

**使用场景**：

do-while 适合「至少需要执行一次」的场景，比如：

- 用户菜单：至少显示一次菜单，然后根据用户选择决定是否继续
- 输入验证：至少请求一次输入，然后验证是否合法

## 3.6 break 语句

break 用于<font color="red">**立即退出当前循环**</font>或 switch 语句。

**在 for 循环中使用**：

```java
for (int i = 1; i <= 10; i++) {
    System.out.println("当前值: " + i);
    
    // 当 i 等于 5 时跳出循环
    if (i == 5) {
        System.out.println("达到目标值 5，跳出循环！");
        break; // 跳出循环
    }
}
```

上述代码预计做 10 次循环，但是当满足条件 `i==5` 时，会进入 if 语句执行 if 内部的代码。在 if 内部会出现 break 语句，当 for 循环遇到 break 时会<font color="red">**终止整个循环**</font>，即 `i=6` 不会再执行了。

整个循环只执行了 5 次（`i=1` 到 `i=5`）。

## 3.7 break 在嵌套循环中的作用

对于 break 我们要特别注意它在嵌套循环里的作用：

```java
for (int i = 1; i <= 3; i++) {
    System.out.println("外层循环 i = " + i);
    
    for (int j = 1; j <= 3; j++) {
        System.out.println("  内层循环 j = " + j);
        
        // 当内层循环到2时跳出内层循环
        if (j == 2) {
            System.out.println("  跳出内层循环");
            break; // 只跳出内层循环
        }
    }
}
```

**问题**：当遇到 break 时，到底是跳出内层循环还是跳出所有的循环（即内外层循环都终止）？

**输出结果**：

```
外层循环 i = 1
  内层循环 j = 1
  内层循环 j = 2
  跳出内层循环
外层循环 i = 2
  内层循环 j = 1
  内层循环 j = 2
  跳出内层循环
外层循环 i = 3
  内层循环 j = 1
  内层循环 j = 2
  跳出内层循环
```

很明显，每当内层循环满足 `j=2` 时，进入 if 语句，遇到 break。但这个 break<font color="orange">**只会跳出内层循环**</font>，接着继续执行外层的循环。

**关键规则**：break 只会跳出<font color="red">**当前循环**</font>，并不会跳出外层循环。

## 3.8 continue 语句

**作用**：跳过当前循环的剩余代码，进入下一次迭代。

continue 同 break 不同：

- **break**：强制结束当前循环（无论还剩余多少次都不再执行）
- **continue**：仅跳过本次迭代，进入下一次迭代

用示例解释会更加清楚：

```java
// 跳过偶数
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;  // continue语句会跳过本次迭代，进入下一次迭代
    // 每当i是偶数时不会执行下面的打印语句
    System.out.println(i); // 输出奇数 1,3,5,7,9
}
```

**执行流程**：

- `i=0`：`0 % 2 == 0` 成立，执行 continue，跳过打印，进入下一次迭代
- `i=1`：`1 % 2 == 0` 不成立，不执行 continue，执行打印，输出 1
- `i=2`：`2 % 2 == 0` 成立，执行 continue，跳过打印，进入下一次迭代
- `i=3`：`3 % 2 == 0` 不成立，不执行 continue，执行打印，输出 3
- ……以此类推

## 3.9 break vs continue 对比

| 特性 | break | continue |
|------|-------|----------|
| 作用 | 终止整个循环 | 跳过本次迭代 |
| 后续迭代 | 不再执行 | 继续执行 |
| 使用场景 | 找到目标后提前退出 | 跳过不需要的情况 |
| 示例 | 查找数组中第一个匹配项 | 过滤数组中的某些元素 |

```java
// break示例：找到第一个偶数就退出
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        System.out.println("找到第一个偶数: " + i);
        break; // 找到后不再继续
    }
}
// 输出：找到第一个偶数: 2

// continue示例：打印所有奇数
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue; // 跳过偶数
    System.out.println(i);
}
// 输出：1 3 5 7 9
```
