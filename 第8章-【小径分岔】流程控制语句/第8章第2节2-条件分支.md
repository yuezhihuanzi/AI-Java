## 2.1 if 语句

条件语句可以根据不同条件结果做出不同的反应。在现实世界里，我们需要根据条件来做出不同的反应：如果今天下雨，就在家看书；否则就出去逛街。

**基本结构**：

```java
if (condition) {
    // 条件为 true 时执行
}
```

`condition` 通常是一个表达式，当表达式计算结果为 `true` 时才会执行 `{}` 里的代码：

```java
int a = 3;
int b = 3;
if (a == b) {
    // 只有 a和b相等时才会执行下面的代码
    System.out.println("今天出去玩");
}
```

## 2.2 if-else 语句

当需要二选一时，使用 if-else 结构：

**基本结构**：

```java
if (condition) {
    // 条件为 true 时执行
} else {
    // 条件为 false 时执行
}
```

**示例**：

```java
int a = 3;
int b = 3;
if (a == b) {
    // 只有 a和b相等时才会执行下面的代码
    System.out.println("今天出去玩");
} else {
    // a和b不相等时会执行下面的代码
    System.out.println("今天不出去玩");
}
```

if-else 会根据条件的不同选择执行其中的一个分支。要不执行 if 里的语句，要不执行 else 里的语句，<font color="red">**不会同时执行两个**</font>。

## 2.3 if-else if-else 多分支

当需要更多分支选择时，可以使用 if-else if-else 结构：

```java
int score = 85;

if (score >= 90) {
    System.out.println("优秀");
} else if (score >= 80) {
    System.out.println("良好"); // 满足此分支条件，输出此项
} else if (score >= 60) {
    System.out.println("及格");
} else {
    System.out.println("不及格");
}
```

执行流程：

1. 首先判断 `score >= 90` 是否成立
2. 如果不成立，继续判断 `score >= 80`
3. 如果还不成立，继续判断 `score >= 60`
4. 如果都不成立，则执行最后的 `else` 分支

**关键规则**：

- 每个分支都会判断是否满足条件
- 满足即执行相应的分支，然后<font color="red">**跳出整个 if-else 结构**</font>
- 不满足则进行下一个分支的判断
- 如果都不满足，则执行最后的 else 分支（如果有的话）

## 2.4 if-else if-else 的局限性

当条件分支过多时，其实不适合用 if-else if-else 语句。比如有 10 个、20 个分支需要判断，代码会变得冗长且难以维护。这种情况下，更适合使用 switch-case 语句。

```java
// 不推荐：分支过多时
if (day == 1) {
    System.out.println("星期一");
} else if (day == 2) {
    System.out.println("星期二");
} else if (day == 3) {
    System.out.println("星期三");
} else if (day == 4) {
    System.out.println("星期四");
} else if (day == 5) {
    System.out.println("星期五");
} else if (day == 6) {
    System.out.println("星期六");
} else if (day == 7) {
    System.out.println("星期日");
} else {
    System.out.println("无效日期");
}
```

这种情况更适合用下一节要学习的 switch-case 语句。

## 2.5 传统 switch-case 语句

switch-case 语句非常适合表达分支很多的情况。

**基本结构**：

```java
switch (expression) {
    case value1:
        // 代码块1
        break;
    case value2:
        // 代码块2
        break;
    // 更多case...
    default:
        // 默认代码块
}
```

**示例**：

```java
String color = "BLUE";
switch (color) {
    case "GREEN":
        System.out.println("绿色");
        break;
    case "YELLOW":
        System.out.println("黄色");
        break;
    case "BLUE":
        System.out.println("蓝色"); // 打印此项
        break;
    case "ORANGE":
        System.out.println("橙色");
        break;
    default:
        System.out.println("未知颜色");
}
```

switch-case 语句会判断每个分支条件，如果成立就会进入该分支执行代码。如果所有分支都没有命中，那么就会执行最后的 `default`（默认）里的语句。

## 2.6 穿透机制（Fall-through）

这里要特别注意每个分支里的 `break`：其作用是<font color="red">**终止整个 switch 语句**</font>。

如果 case 语句内部没有 break，Java 会继续执行后续 case 的代码，<font color="orange">**无论条件是否匹配**</font>。这种现象称为「<font color="blue">穿透</font>」（Fall-through）：

```java
int day = 2;
switch (day) {
    case 1:
        System.out.println("星期一");
    case 2:
        System.out.println("星期二"); // 匹配此case
    case 3:
        System.out.println("星期三"); // 继续执行！
    case 4:
        System.out.println("星期四"); // 继续执行！
    default:
        System.out.println("无效日期"); // 继续执行
}

/* 输出：
星期二
星期三
星期四
无效日期
*/
```

可以看到，虽然代码只匹配 `case 2` 这个分支，但由于 `case 2` 中没有 break，所以 Java 会继续执行后续所有的 case，直到遇到 break 语句。如果没有 break 语句，则会执行全部的 case。

**正确的使用方式**：

```java
int day = 2;
switch (day) {
    case 1:
        System.out.println("星期一");
        break; 
    case 2:
        System.out.println("星期二"); // 执行此处
        break; // 立即退出switch，后续语句不再执行
    case 3:
        System.out.println("星期三");
        break;
    case 4:
        System.out.println("星期四");
        break;
    default:
        System.out.println("无效日期");
        break;
}

// 输出：星期二
```

## 2.7 故意穿透的应用

在某些场景下，故意不使用 break 可以实现多条件共享代码：

```java
String day = "WED";
switch (day) {
    case "MON":
    case "TUE":
    case "WED":
    case "THU":
    case "FRI":
        System.out.println("工作日");
        break;
    case "SAT":
    case "SUN":
        System.out.println("周末");
        break;
    default:
        System.out.println("无效日期");
        break;
}
// 输出"工作日"
```

上述代码的前 5 个 case（MON-FRI）可以「穿透」，直到遇到 break，这样可以实现 5 个 case 里任意 1 个分支命中，都可以输出「工作日」。

## 2.8 现代 Java 的 switch 表达式

从 Java 12 开始（Java 14 正式标准化），我们可以用更简单的方式来编写 switch-case。

**新特性**：

- 使用箭头 `->` 语法自动阻断穿透，不再需要 break
- 每个 case 语句可以返回值
- 支持多个 case 共享一个分支（用逗号分隔条件）
- 可作为表达式使用（赋值、返回等）

**示例**：

```java
String day = switch (3) {
    case 1 -> "Monday";     // 自动阻断穿透，没有break也不会穿透到下一个case
    case 2 -> "Tuesday";
    case 3 -> "Wednesday";
    default -> "Unknown";
};
System.out.println(day); // 输出 Wednesday
```

不同于传统写法，上述每个 case 最终会返回值，所以我们用了一个 String 类型的变量 `day` 来接收这个值。

**合并多个分支**：

```java
int num = 5;
String result = switch (num) {
    case 1, 3, 5, 7, 9 -> "Odd";      // 奇数
    case 2, 4, 6, 8, 10 -> "Even";    // 偶数
    default -> "Out of range";
};
System.out.println(result); // 输出 Odd (奇数)
```

**使用 yield 关键字**：

如果想在每个 case 里写多行语句，可以用 `yield` 关键字：

```java
int score = 85;
String result = switch (score / 10) {
    case 10, 9 -> "优秀";
    case 8 -> "良好";
    case 7 -> "中等";
    case 6 -> {
        System.out.println("及格边缘");
        yield "及格"; // 相当于返回+break
    }
    default -> "不及格";
};
```

`case 6` 的代码块中可以写任意语句来实现复杂的功能，最后用 `yield` 返回值。

> **最佳实践**  
> <font color="orange">优先使用现代 switch，传统的 switch-case 非常容易出错。</font>

## 2.9 switch-case 的最佳实践

无论传统写法还是现代 Java 的高级写法，都可以在任意的 case 分支里写多条语句。但<font color="red">**建议程序员不要在 case 里写过多的语句**</font>。

有些程序员会在 case 语句里写几十行代码，这是非常不好的做法，因为它会让代码变得非常难以阅读。

如果在每个分支里确实有复杂的逻辑，需要写多行语句，最好的方法是将这些语句提取为一个方法，然后仅在 case 里调用这个方法：

```java
String command = "stop";
switch (command) {
    case "start" -> startService();
    case "stop" -> stopService();
    case "restart" -> restartService();
    case "status" -> showStatus();
    default -> showHelp();
}
```

每个 case 里的语句可以提炼为一个方法，仅在 case 里调用方法。

## 2.10 常见陷阱

**错误 1：忘记写 break**

```java
int option = 1;
switch (option) {
    case 1: 
        initSystem(); // 会继续执行case2！
    case 2:
        startService(); // 非预期执行
        break;
}
```

**错误 2：default 位置不当**

```java
switch (x) {
    default: 
        handleError(); // 没有break会继续执行case1！
    case 1:
        process();
}
```

## 2.11 防御性编程技巧

如果担心出现一些意外的错误，可以采用一些防御性的编程技巧：

**技巧 1：总是添加 break（即使是 default 分支）**

```java
switch (x) {
    default:
        handleDefault();
        break; // 明确添加
}
```

**技巧 2：注释说明是故意穿透**

```java
switch (level) {
    case HIGH:
        enableTurboMode();
        // 穿透到MEDIUM分支是设计意图
    case MEDIUM:
        enableFeature(); 
        break;
}
```
