## 6.1 任务要求

1. 根据冒险者等级和区域最低等级判断能否进入。
2. 已通关区域不能再进入，不能重复获取奖励。
3. 主菜单用 `switch-case`：
   - 1. 查看状态
   - 2. 探索区域
   - 3. 进入商店
   - 4. 退出
4. 菜单循环正常运行。

## 6.2 [P] 预测——这段代码会输出什么

```java
class DecisionDemo {
    public static void main(String[] args) {
        int level = 3;
        int requiredLevel = 5;

        if (level < requiredLevel) {
            System.out.println("等级不足，需要" + requiredLevel + "级");
        } else {
            System.out.println("准入通过");
        }

        int choice = 2;
        switch (choice) {
            case 1:
                System.out.println("查看状态");
                break;
            case 2:
                System.out.println("探索区域");
            case 3:
                System.out.println("进入商店");
                break;
            case 4:
                System.out.println("退出");
                break;
            default:
                System.out.println("无效选择");
        }
    }
}
```

预测：

1. 准入判断输出什么？
2. `choice = 2` 时会输出哪些行？
3. 为什么 `case 2` 后面会继续输出「进入商店」？

## 6.3 [R] 运行——验证预测

运行结果：

```text
等级不足，需要5级
探索区域
进入商店
```

`case 2` 没有 `break`，程序会继续执行下一个 `case`，这就是 <font color="orange">switch 穿透</font>。

## 6.4 [I] 研究——调试练习

找出下面代码中的 3 处错误：

```java
class MenuTest {
    public static void main(String[] args) {
        int choice = 2;

        switch (choice) {
            case "1":
                System.out.println("查看状态");
                break;
            case "2":
                System.out.println("探索区域");
                break;
            case "3":
                System.out.println("退出");
                break;
        }

        int level = 5;
        int requiredLevel = 3;
        if (level <= requiredLevel) {
            System.out.println("可以进入");
        } else {
            System.out.println("等级不足");
        }
    }
}
```

先自己找，想一想：

- `switch` 的选择器和 `case` 的类型必须一致吗？
- 所有选项都不匹配时，程序会怎样？
- `level <= requiredLevel` 表达的准入条件和代码意图一致吗？
