## 6.2 [P] 预测——这段代码会输出什么

```java
import java.util.*;

class Main {
    public static void main(String[] args) {
        List<String> names = Arrays.asList("Charlie", "Alice", "Bob");
        names.sort((a, b) -> a.compareTo(b));
        System.out.println(names);

        Optional<String> found = names.stream()
            .filter(n -> n.startsWith("B"))
            .findFirst();
        System.out.println(found.orElse("未找到"));
    }
}
```

预测：
1. 排序后的列表是什么？
2. `findFirst()` 返回什么类型？
3. `orElse("未找到")` 什么时候生效？

## 6.3 [R] 运行——验证预测

```
[Alice, Bob, Charlie]
Bob
```

`Optional` 表示"可能有值"。用 `ifPresent()` 和 `orElse()` 可以避免空值判断。
