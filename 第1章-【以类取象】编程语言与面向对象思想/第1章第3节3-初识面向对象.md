## 3.2 数据的分类打包思维

考虑一个搬家的场景。假如有海量的物品需要从一个家搬到另一个家，这些物品有针线、书籍、游戏光碟、唱片、杂物等。如果不做任何处理，直接一件件地将这些小物品从三十二层的高楼拿到一楼的汽车里；然后将汽车开到新家的楼下，再一件件地将这些小物品全部搬到新家。这个过程先不说人会不会崩溃，针线可能会遗失，书籍、唱片可能会出现划痕而损坏。总之，这个过程很痛苦，还有很大的风险。

而数据就像这一堆堆的小物品，「搬家」对应着如何将数据输入到计算机中，让它帮我们解决问题。

![杂乱的物品](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/%E6%9D%82%E4%B9%B1%E7%9A%84%E7%89%A9%E5%93%81%EF%BC%88%E5%AE%9A%E7%A8%BF%EF%BC%89.jpg)

为什么不先将这些物品分类打包呢？将一千个小物品打包装在箱子里，显然比一件件搬到新家更方便，也更不容易损坏。

![三个箱子](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/%E4%B8%89%E4%B8%AA%E7%AE%B1%E5%AD%90%282%29.jpg)

面向对象类似上面的场景，它本身就是一种<font color="red">「分类打包」</font>的思维。如果要让计算机计算很简单的问题，比如「1+1 等于几」，那只输入少量数据即可，根本用不上分类打包。

但当计算复杂问题的时候，我们就需要向计算机输入海量的数据，这时候将数据「分类打包」就很有必要。

以天气预报为例，将不同地区的温度值、测量高度、单位、风向、风速、降水类型、降水强度、降水持续时间杂乱无章地输入到计算机，显然没有将这些数据分类成「温度」、「风」、「降水」这三类后再输入更方便。

![天气预报分类](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/%E5%A4%A9%E6%B0%94%E9%A2%84%E6%8A%A5%E5%88%86%E7%B1%BB.jpg)

问题在于怎么分类比较好。

A 同学选择把游戏碟、书籍放一起，衣服和针线放一起，水杯和唱片放一起。这样显然有问题。大多数同学不会这么做，而是会按物品的类别来分类：将所有书籍放一起、所有游戏碟放一起，即将同类物品打包在一个箱子里。

其实人类世界本身就已经将类分好了，不需要绞尽脑汁地创建新的分类。在我们的认知里，世界的一切都是由物质构成，猫、树、车本身就是最好的分类。<font color="red">「面向对象」就是用人类最熟悉的各种事物将数据进行打包分组。</font>

比如，猫类可以包含猫的年龄、体重、性别；车可以包含车的品牌、油耗、重量、最高时速等数据。当向计算机输入数据时，我们只需要选择最熟悉的事物种类组织数据，再将数据打包给计算机即可。

![类与属性](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/%E7%B1%BB%E4%B8%8E%E5%B1%9E%E6%80%A7.jpg)

![面向对象核心](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/image-4.png)

现实中的任何事物都可以作为一种分类来打包数据并输入到计算机中。

## 3.3 Java 与面向对象——强制打包的语言

![Java强制面向对象](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/image-5.png)

首先需要理解，<font color="orange">面向对象只是一组数据的组织方式，它不是必须的</font>，只是使用面向对象可以让我们更好地同计算机交流。

比如，在之前的案例里，如果直接将天气预报的所有数据一个一个地输入到计算机中，不去「打包」，这样可以吗？

可以，但这很繁琐。处理复杂问题时，需要耗费大量的精力，而且还容易出错。

如果非要一个个地输入数据，没有问题。使用 Python 语言，可以选择「分类打包」输入数据，也可以「不分类」直接输入数据。

但 <font color="red">Java 不可以</font>。在 Java 中，无法直接将数据输入到计算机中。比如对于天气预报中的「风向」与「风速」，如果使用 Python 语言，可以直接将这两项数据的数值输入到计算机中。但在 Java 中，必须使用一个叫做「<font color="blue">类</font>」的东西来将这两个数据打包，再输入到计算机中。

![Python与Java对比](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260828_090204/2-%E5%88%9D%E8%AF%86%E9%9D%A2%E5%90%91%E5%AF%B9%E8%B1%A1/imgs/pthony%E5%92%8Cjava.jpg)

关于「类」这个概念，目前可以不用深入了解，只需要知道「类」通常用来打包数据。

虽然还没有学习任何编程语法，但可以来看看如果想将风速、风向、风速单位这三项数据输入到计算机中，用 Python 语言和 Java 语言有什么不同。对于下面的代码，读者只需要看看大概的结构和形式，无需理会每段代码的含义，所有的细节语法将在后续章节学习。

```python
# 使用Python输入风向、风速、风速单位3项数据
wind_direction = '北风'
wind_speed = 18.5
wind_speed_unit = 'm/s'
```

输入上述的 3 行代码，计算机立刻就能理解这 3 项数据，随后就可以用这些数据进行计算。但是 Java 就没有这么简单了：

```java
// 使用Java 定义一个Weather类来存储风向、风速和风速单位
class Weather {
    private String windDirection; // 风向
    private double windSpeed;     // 风速
    private String windSpeedUnit; // 风速单位

    // 构造方法
    public Weather(String windDirection, double windSpeed, String windSpeedUnit) {
        this.windDirection = windDirection;
        this.windSpeed = windSpeed;
        this.windSpeedUnit = windSpeedUnit;
    }
}

public class Main {
    public static void main(String[] args) {
        // 创建一个Weather对象
        Weather weather = new Weather("东北风", 12.5, "m/s");
    }
}
```

绝大多数读者在看到这段 Java 代码时一定会感到困惑：为什么放着简单的 Python 不用而要学习 Java 呢？一个经过三十多年发展的语言，必然有它的道理。

Java 之所以显得复杂，主要是因为 Java 必须使用面向对象的方式和计算机进行交流。相对于 Python 简单的 3 行输入，Java 使用了一个类将 3 项数据「打包」在它的内部。

上述代码中的 `class` 关键字定义了一个名为 `Weather` 的类，它就是前面搬家时的「箱子」，这个箱子里装了 3 项关于「风」的基本数据。至于其他的代码，暂时不需要理解。

对于 Java，哪怕再简单的数据输入（比如只录入 1 项风向数据），也必须使用 `class` 来定义一个「箱子」，再将数据打包进「箱子」中。<font color="red">Java 不允许像 Python 那样直接将数据输入到计算机中。</font>

使用面向对象来同计算机交流，确实比直接输入数据要繁琐很多。但 Python 如果同样使用面向对象来编写上述案例，也会显得复杂：

```python
# 定义一个Weather类
class WeatherData:
    def __init__(self, wind_direction, wind_speed, wind_speed_unit):
        self.wind_direction = wind_direction
        self.wind_speed = wind_speed
        self.wind_speed_unit = wind_speed_unit

# 创建一个WeatherData对象
weather = WeatherData("西南风", 8.3, "m/s")
```

由于 Python 语言的特性，它的面向对象代码略微比 Java 简单一些，但面向对象的基本结构同 Java 类似，同样使用了 `class` 关键字，并在内部「打包」了 3 项数据。

面向对象是一种数据的组织机制，也是一种思维，它不属于特定的语言。任何语言都可以支持面向对象，常见的面向对象语言有 Java、C#、C++。一些非典型面向对象语言也可以支持面向对象，比如 Python、JavaScript。

Python 可以用面向对象的机制同计算机交流，也可以不使用面向对象，直接输入各种数据。但 Java 不可以，<font color="red">Java 只能使用面向对象</font>。

还有一类语言，比如 C 语言，并不支持面向对象。
