## 2.1 为什么机器听不懂人话？

首先，你需要理解为什么会出现编程语言？

人类早期在做计算类任务的时候非常吃力，比如在没有计算机的时代，19 世纪数学家尚克斯（William Shanks）耗时 15 年才将圆周率 π 计算到 707 位；强如欧拉这种天才数学家，也只能用 1 小时完成圆周率 20 位小数的计算，这个速度已经在当时震惊了整个数学界。

但在有了计算机后，100 万位圆周率 π 的计算仅需要 1 秒钟。

![数学家尚克斯](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260827_140854/1-%E7%BC%96%E7%A8%8B%E8%AF%AD%E8%A8%80%E7%9A%84%E6%9C%AC%E8%B4%A8/imgs/%E6%95%B0%E5%AD%A6%E5%AE%B6%E5%B0%9A%E5%85%8B%E5%B2%81.jpg)

再举个例子，在 1950 年左右人口普查手工统计可能耗时需要 1 年，而利用计算机做数据统计，可能仅用十小时左右就能完成人口普查统计。

![人口普查](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260827_140854/1-%E7%BC%96%E7%A8%8B%E8%AF%AD%E8%A8%80%E7%9A%84%E6%9C%AC%E8%B4%A8/imgs/%E4%BA%BA%E5%8F%A3%E6%99%AE%E6%9F%A5.jpg)

计算机提高的不仅仅是计算速度，还有强大的容错能力。尚克斯虽然将圆周率计算到了小数点后 707 位，但后来被证明从 528 后均为错误。如果是计算机，它不会出现错误。

很显然，用计算机来计算比人类手工计算省时省力，还不容易出错。但问题是，计算机如果要帮助我们计算，就需要充分了解我们的问题并能够接收数据用于计算。

如果计算机需要理解「猫」，那它需要理解猫的爪子、毛色、年龄。

这些都需要被「输入」到计算机中。但怎么输入？

## 2.2 编程语言——人机交流的翻译官

![编程语言不通](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260827_140854/1-%E7%BC%96%E7%A8%8B%E8%AF%AD%E8%A8%80%E7%9A%84%E6%9C%AC%E8%B4%A8/imgs/%E7%BC%96%E7%A8%8B%E8%AF%AD%E8%A8%80%E4%B8%8D%E9%80%9A.jpg)

很多同学在初学编程语言时，总是将注意力集中在「编程」上，但其实理解<font color="red">「编程语言是一种语言」</font>这个观点更重要。有了这个基本概念，你就能更好地理解 Java 中很多抽象的概念。

编程语言其实本质上和「汉语」、「英语」没有区别，汉语、英语是为了让人与人之间可以交流，而<font color="red">编程语言是为了人与计算机之间可以交流</font>。

以「人口普查统计」为例，我们必须告知计算机人口普查的数据、并告诉它怎么统计，它才能帮助我们计算。

而「人口普查」也仅仅只是人类浩如烟海问题中的其中一种。理论上，如果计算机要帮助人类计算所有的问题，那计算机就必须理解人类世界中任意的一件事物，比如一棵树、一辆车、一只猫……；同时也需要理解树的高度、车的速度、猫的年龄等特征。

换句话来说，<font color="red">现实世界里的任何一件事物（以及特征）都必须能够被输入到计算机中并让计算机理解。</font>

![猫车树](https://www.logamee.com/uploads/md_resources/course77/chapter268/20260827_140854/1-%E7%BC%96%E7%A8%8B%E8%AF%AD%E8%A8%80%E7%9A%84%E6%9C%AC%E8%B4%A8/imgs/%E7%8C%AB%E8%BD%A6%E6%A0%91.jpg)

有了编程语言，我们就可以通过这种「语言」将各种事物、以及事物的特征告知计算机，并让计算机为我们解决问题。

接下来，我们需要理解这种语言的规则。

计算机历史上曾出现过的编程语言大约有 300 多种。即使是在现代，我们经常使用的编程语言也有几十种之多。但无论是哪种编程语言，表面上看它们的语言规则不同，但它们本质上都是在做同一件事——<font color="blue">**翻译**</font>。

## 2.3 思辨问答

**如果编程语言是「翻译」，那谁来决定翻译的标准？**

正文提到编程语言的作用是翻译人类意图。但问题是——谁来定义「猫」这个类应该有哪些属性？年龄、毛色、品种？谁来规定？

答案是：<font color="red">**程序员**</font>。

这意味着同一个事物，不同的程序员可能会定义出不同的类。有人可能把「猫」定义为：

- 属性：名字、年龄、毛色
- 行为：睡觉、吃饭、撒娇

也有人可能定义为：

- 属性：ID、品种、体重、疫苗记录
- 行为：抓老鼠、体检、繁殖

两种定义都对，取决于你的程序需要什么。这就是编程的<font color="blue">**设计选择**</font>——没有唯一正确答案，只有「更适合当前场景」的答案。

---

**「一切事物都必须先定义才能存在」——那「定义」本身是谁定义的？**

这句话触及了一个更深层的问题：Cat 类是谁定义的？

在 Java 中，<font color="red">**类是由程序员编写的**</font>。但 Java 语言本身的规则（比如 class 关键字、字段和方法的结构）是由<font color="red">**语言设计者**</font>定义的。

这就好比：

- 你用汉语写小说 → 你是作者，但汉语的语法是语言学家和历史演化决定的
- 你用 Java 写类 → 你是程序员，但 Java 的语法是 James Gosling（Java 之父）和团队设计的

所以「定义」本身也是被定义的。这听起来像循环论证，但它是编程语言的基础——<font color="red">**语言规则是约定，不是自然法则**</font>。

---

**如果 AI 能自动生成代码，我还需要学编程吗？**

前面提到 AI 可以充当翻译官，但没深入讨论它自动生成代码这件事。

AI 确实能帮你写代码。但问题是：<font color="red">**你需要告诉 AI 要什么**</font>。

如果你不知道「类」是什么，你就无法告诉 AI「帮我创建一个 Cat 类」。如果你不理解「属性」和「行为」的区别，你就无法判断 AI 生成的代码对不对。

AI 是工具，不是替代品。理解概念，你才能使用工具。不理解概念，工具也无法帮你。
