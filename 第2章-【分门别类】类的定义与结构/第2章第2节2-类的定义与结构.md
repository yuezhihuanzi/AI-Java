## 2.1 如何在 Java 中定义一个类

之前的章节，我们了解了「类」的作用，它主要的作用是将现实世界里的数据进行「分类」和「打包」。

- 猫类可以将猫的年龄、毛色等数据打包
- 汽车类可以将汽车的时速、油耗、颜色等特征数据打包

那么问题来了：<font color="red">**这些类和数据在 Java 中应该怎么表示呢？**</font>

换句话说，我要如何用 Java 语言来描述这些事物和数据？

### class 关键字

Java 作为一种编程语言，它同样有自己的「语法规则」。<font color="red">**学习编程其实就是在学习编程语言的语法。**</font>

下面我们来看看，Java 如果要表示一个「类」，它将使用什么样的语法规则。

![语法规则](https://www.logamee.com/uploads/md_resources/course77/chapter269/20260827_145903/1-%E7%B1%BB%E7%9A%84%E5%AE%9A%E4%B9%89%E4%B8%8E%E7%BB%93%E6%9E%84/imgs/%E8%AF%AD%E6%B3%95%E8%A7%84%E5%88%99.jpg)

汉语中「类」这个词，翻译成英语可以用 `class`。而 Java 直接使用 `class` 来表示一个类。

假如我们想表达「猫」这个类，在 Java 中，可以首先新建一个 `Cat.java` 的文件（如何新建文件，请参考附录 A），并在该文件中这么写：

```java
class Cat {

}
```

我们逐字分析上述代码：

- `class` 表示一个类，当我们要定义一个类时，<font color="red">**必须使用 class 关键字**</font>
- 而每个类都需要一个名字，称为「类名」，上述代码中 `Cat` 即为类名
- 类名与 `class` 关键字之间需要有一个「空格」将它们分隔开

在类名后，跟着一对花括号 `{ }`。在 Java 语言中，`{}` 的作用是包裹一段代码，<font color="red">**凡是在 `{ }` 中的代码均属于当前类的代码**</font>。

这个很好理解，Cat 是一个类，但只有类是不行的。类还有一些特征数据，比如我们举例的「猫」这个类，它还有年龄、毛色等数据。

### 这些数据写在哪里？

答案是需要写在 Cat 后面的 `{ }` 里。只有在 `{ }` 里的代码才属于 Cat 这个类。看看下面的代码：

```java
class Cat {
  int age;        // 必须结尾加分号，表示一条语句结束了
  String color;
}
```

> **[!] Java 代码以语句为单位**  
> 通常每条语句占据一行。<font color="red">**每条语句都必须以英文分号 `;` 来结尾**</font>。如果不加分号，Java 会报错。

上述代码中的 `age`、`color` 表示年龄、颜色，它们属于 Cat 这个类的特征数据。通常，我们将类 `{ }` 里的内容称为「<font color="blue">类体</font>」。<font color="red">**Java 所有的代码都必须写在「类体」里**</font>。

如果你写成下面这样：

```java
class Cat {
  int age;
}
String color;    // × 错误！
```

这是不对的。`color` 出现在了 `{ }` 外部，如果你这样写，Java 会提示你代码出现了错误，它违反了 Java 的语法规则。

### 关于花括号的位置

这里还需要注意，`{ }` 中的左括号紧跟 Cat 后面不换行，这是 Java 提倡的一种规范。

如果你写成下面的形式：

```java
class Cat 
{              // × 不符合Java规范
  int age;
  String color;
}
```

这在语法上是可行的（即 Java 不会报错），但这不符合 Java 的规范。每种语言都有自己的一套规范，比如上述代码的风格其实是 C# 这种语言的规范，它提倡首尾括号换行；但 Java 与之相反，它提倡首括号不换行。

![花括号规范](https://www.logamee.com/uploads/md_resources/course77/chapter269/20260827_145903/1-%E7%B1%BB%E7%9A%84%E5%AE%9A%E4%B9%89%E4%B8%8E%E7%BB%93%E6%9E%84/imgs/image-3.png)

> **[!] 类名命名规范**  
> - 类名通常使用名词  
> - <font color="red">**public 类**</font>名必须与所在 java 文件名相同（非 public 类可以不同）  
> - 类名通常采用「<font color="blue">大驼峰</font>」（所有单词首字母必须大写）的形式来表示  
> - 例如：`Cat`、`Pear`、`MyDog`

## 2.2 类的两大组成部分

下面先看一个完整的类。

![类的组成部分](https://www.logamee.com/uploads/md_resources/course77/chapter269/20260827_145903/1-%E7%B1%BB%E7%9A%84%E5%AE%9A%E4%B9%89%E4%B8%8E%E7%BB%93%E6%9E%84/imgs/image-4.png)

理论上，<font color="red">**现实世界里任何事物的相关数据都可以在 Java 中用类来封装**</font>。

比如：

- 猫的相关数据可以在计算机里装在一个名为 Cat 的类中
- 一棵树的数据可以在计算机里装在一个名为 Tree 的类中

在第 1 章中，为了便于你入门 Java，我们将类解释为对数据的封装，这当然没有错，但这只是类的一种最基本的作用。

事实上，现实世界里的任何事物，都必须在计算机里能够被表示出来，<font color="red">**而类就是现实世界里事物在计算机里的一种表达方式**</font>。

那么，怎么表达？我们需要扩展两个概念：<font color="blue">**特征**</font>和<font color="blue">**行为**</font>。

现实世界里的任何事物，都有自己的特征和行为。

**特征**很好理解，比如：

- 猫的名字、年龄
- 人的身份证号
- 车的油耗、颜色

这些特征用来描述一件事物以及区别彼此。比如，你叫张三，她叫赵六，这两个特征数据就将彼此区分开了。

**行为**表示一个事物能「做什么」，它往往表示「动作」。比如：

- 人：看电影、吃饭、读书、点外卖
- 猫：睡觉、打呼、撒娇

所以，换到计算机里，「类」也要能够表达特征和行为。以猫为例，Cat 类就有以下的特征和行为：

**特征**：年龄、毛色、品种等特征数据  
**行为**：吃饭、喝水、抓老鼠

### 类的特征

下面看字段的基本表达形式。

![字段](https://www.logamee.com/uploads/md_resources/course77/chapter269/20260827_145903/1-%E7%B1%BB%E7%9A%84%E5%AE%9A%E4%B9%89%E4%B8%8E%E7%BB%93%E6%9E%84/imgs/image-5.png)

下述代码给出了特征的基本表达形式：

```java
class Cat {
  int age;
  String color;
}
```

其中 `age`、`color` 就是当前 Cat 类的特征数据，表示猫的年龄和颜色。

<font color="red">**在 Java 中这些特征有一个专门的名字，叫「字段」（Field）。**</font>

> **关于称呼的说明**  
> 字段（Field）是 Java 官方文档中的标准称谓。但不同的语言对于同一种机制有不同的称呼。在正式场合，程序员最好遵循 Java 官方的称谓，使用「字段」。

这里我们只需要知道：<font color="red">**「字段」是用来表示一个类的特征，并知道字段属于类的一部分即可。**</font>

### 关于变量的类型

上述代码中字段 `age`、`color` 前的 `int`、`String` 表示字段的类型：

- `int` 表示「整数」类型
- `String` 表示「字符串」类型

这符合年龄、颜色这类数据在现实里的类型：

- 一般说到年龄，我们会用整数来表示
- 而描述颜色，我们往往用「红色」、「蓝色」等文本

关于变量与变量的类型，它很重要，但我们暂时放放，不用着急，<font color="orange">**目前我们最重要的是对「类」有一个全面的了解**</font>。

> **字段的命名规范**  
> 因为字段往往表示事物的「特征」，所以：  
> - 字段通常以 **名词** 来命名，比如「颜色」- `color`、「年龄」- `age`  
> - 字段通常以名词 **小写** 的形式来表示，比如 `age`  
> - 如果是多个名词的组合，需要以「<font color="blue">小驼峰</font>」（首单词字母小写，其余单词首字母大写）的形式来表示  
> - 例如：`myAge`、`yourFavoriteColor`

### 类的行为

如果我们想为 Cat 类添加一个「喝水」的行为，可以向 Cat 类添加以下代码：

```java
class Cat {
  int age;
  String color;
  
  void drinkWater() {
    // 下面的打印代码可以暂时忽略
    System.out.println("猫正在喝水...");
  }
}
```

代码中的第 6 到第 8 行即为一个极其简单的 Java 方法。上述代码为 Cat 添加了一个行为：喝水，它是用 `drinkWater` 这个方法来表示的。

我们来逐步分析这个方法：

- 我们暂时忽略掉 `void` 这个关键字
- `drinkWater` 是当前方法的 **方法名**
- 方法名后有一对小括号 `( )`，<font color="red">**这对括号中即使是空的也必须存在，不能省略**</font>
- 接着是一对花括号 `{ }`，这对括号的作用类似于定义「类」时用的 `{ }`，其中的代码表示它们属于当前方法，称为「<font color="blue">方法体</font>」

在方法体中，我们可以编写任意的 Java 代码去实现任意的功能。上述示例里的 `System.out.println` 将「猫正在喝水」的文本打印在计算机屏幕上。

**如果一个方法存在于类的类体里，那么这个方法通常也被称为「方法」**（表示方法属于当前类）。

与字段一样，<font color="red">**Java 的方法也只能存在于类体里**</font>。如果你尝试将方法写在类的外部，Java 会提示错误。

看看下面这段代码：

```java
class Cat {
  int age;
  String color;
}

void drinkWater() {    // × 错误！方法不能写在类的外部
  System.out.println("猫正在喝水...");
}
```

这段代码根本无法执行，Java 将给你显示一个大大的错误提示。

但在其他语言里，方法可以位于类的外部，比如在 Python、JavaScript 等语言中。

在很多语言中，方法有时候也被称为「函数」，但在 Java 里，我们一般统一称为「方法」，它表示类的某种行为。

> **方法的命名规范**  
> 由于类的行为通常都是「动作」，比如吃饭、看电影、抓老鼠等，所以：  
> - 方法名通常都用 **动词** 开头  
> - 方法名采用「小驼峰」的形式  
> - 例如：`watchMovie`、`huntMice`、`drinkWater`

## 2.3 类的基本结构总结

本节讲解视频请到 [课程页](https://www.logamee.com/course-learning/77/1482) 观看。

把当前知识点汇总成一张图表。

![类结构总结](https://www.logamee.com/uploads/md_resources/course77/chapter269/20260827_145903/1-%E7%B1%BB%E7%9A%84%E5%AE%9A%E4%B9%89%E4%B8%8E%E7%BB%93%E6%9E%84/imgs/image-7.png)

```text
class 类名 {
  字段1
  字段2
  更多字段...
  
  方法1
  方法2
  更多方法...
}
```

其实类的基本结构非常简单，<font color="red">**每个类分为两大部分：字段与方法**</font>。

当我们定义好类后，剩下的就是在类里不断地添加字段和方法。

<font color="red">**每个类可以添加多个字段和多个方法，没有个数限制。**</font>
