## 4.2 <font color="purple">[I]</font> 研究——分析最小类

先看一个最小的类：

```java
class Cat {
    String name;

    void sleep() {
        System.out.println("猫正在睡觉...");
    }
}
```

拆解结构：

| 组成部分 | 作用 | 示例 |
|---------|------|------|
| `class` 关键字 | 定义类 | `class Cat { }` |
| 字段 | 描述特征 | `String name;` |
| 方法 | 描述行为 | `void sleep() { ... }` |
