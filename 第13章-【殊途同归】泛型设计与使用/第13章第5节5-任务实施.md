## 5.2 [P] 预测——同一个类能装不同类型吗

```java
class Box<T> {
    private T content;

    Box(T content) {
        this.content = content;
    }

    T getContent() {
        return content;
    }
}

class Main {
    public static void main(String[] args) {
        Box<String> stringBox = new Box<>("生命药水");
        Box<Integer> intBox = new Box<>(30);
        System.out.println(stringBox.getContent());
        System.out.println(intBox.getContent());
    }
}
```

预测：
1. `stringBox.getContent()` 返回什么类型？
2. `intBox.getContent()` 返回什么类型？
3. `Box<Double> d = stringBox` 能编译吗？

---

## 5.3 [R] 运行——验证预测

```
生命药水
30
```

泛型让同一个类可以适配不同数据类型。类型参数在编译后会被擦除，所以不能把一个 `Box<String>` 当成 `Box<Double>` 使用。
