## 2.1 default——包私有

`default` 被称为「包私有」修饰符。同一包内的 `default` 元素均可以互相访问，但位于包外的类不能访问包内的 `default` 元素。

`default` 是 Java 默认的访问修饰符——如果一个元素没有任何访问修饰符，那么它就是 `default` 的访问范围。本书前面所有的示例，因为没有访问修饰符，所以都是 `default` 范围。

```java
package com.example;

class Cat {
    int age;          // 没有访问修饰符,实际是default
    private double height;
    
    // 构造函数,实际是default范围
    Cat(int age, double height) {
        this.age = age;
        this.height = height;
    }
}
```

同包中的其他类可以访问：

```java
package com.example;

class Main {
    public static void main(String[] args) {
        // 可以实例化Cat,因为构造函数是default,同包可访问
        Cat cat = new Cat(2, 0.6);
        System.out.println(cat.age);    // 可以访问
        System.out.println(cat.height); // 不可以访问,height是private的
    }
}
```

## 2.2 protected——保护成员

`protected` 修饰符的访问范围为：

- 同一包内的所有类
- 子类可以访问父类的 `protected` 元素，即使子类和父类不在同一个包

`protected` 的重点在于子类可以访问父类里的 `protected` 元素，无论是否同包：

```java
// 父类
package com.example;

class Animal {
    protected String sound = "Animal makes a sound";

    protected void makeSound() {
        System.out.println(sound);
    }
}

// 子类,与父类不在同一个包中
package im.example;

class Cat extends Animal {
    Cat() {
        sound = "Meow";  // 子类修改父类protected属性
    }

    void talk() {
        makeSound();  // 子类调用父类protected方法
    }
}
```

## 2.3 public——完全公开

`public` 是一个公共的完全公开的访问修饰符。被它修饰的元素任何类都可以访问，没有限制。

```java
// 入口类与入口方法通常都是public的
public class Main {
    public static void main(String[] args) {
        System.out.println("Hello");
    }
}
```

## 2.4 访问修饰符可以作用于哪些元素

下表给出了哪些元素可以使用哪些访问修饰符：

| 元素类型 | public | protected | default | private |
|----------|--------|-----------|---------|---------|
| 类/接口 | ✔️ | ✘ | ✔️ | ✘ |
| 嵌套类/内部类 | ✔️ | ✔️ | ✔️ | ✔️ |
| 接口方法 | ✔️ | ✘ | ✘ | ✔️(JDK9+) |
| 类方法 | ✔️ | ✔️ | ✔️ | ✔️ |
| 构造函数 | ✔️ | ✔️ | ✔️ | ✔️ |
| 类字段(成员变量) | ✔️ | ✔️ | ✔️ | ✔️ |
| 接口常量 | ✔️ | ✘ | ✘ | ✘ |
| 局部变量 | ✘ | ✘ | ✘ | ✘ |
| 方法参数 | ✘ | ✘ | ✘ | ✘ |

有几个常见的误区需要澄清。

**不是所有修饰符都可以修饰类**

`private` 和 `protected` 不可以修饰顶层类：

```java
// 错误!private不能作用在class上
private class Cat { }

// public可以
public class Cat { }

// 没有修饰符(相当于default)也可以
class Cat { }

// protected也不行
protected class Cat { }
```

类存在的意义就是被其他类实例化。如果一个类被设置成 `private`，私有的，谁也不能实例化它，那它毫无意义。

**局部变量和方法参数不能被访问修饰符修饰**

基本上同「类」相关的元素才能被访问修饰符修饰：

```java
public class Cat {
    // 错误!public修饰方法参数毫无意义
    void makeSound(public String text) {
        // 错误!protected修饰局部变量毫无意义
        protected String name = "Lily";
        System.out.println(text);
    }
}
```

**构造函数也可以有访问修饰符**

构造函数的访问修饰符控制类能否被其他包实例化。因为实例化的本质就是调用构造函数，所以如果构造函数是 `private` 的，那么任何其他类都不能实例化这个类。

一个不能被实例化的类也是有意义的，比如工具类、需要实现单例模式时：

```java
public class Cat {
    // 私有构造函数
    private Cat() { }

    void makeSound(String text) {
        System.out.println(text);
    }
}

// 错误!private的构造函数无法在外部调用
Cat cat = new Cat();
```
