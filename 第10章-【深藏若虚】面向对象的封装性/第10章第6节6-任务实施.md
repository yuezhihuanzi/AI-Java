## 6.2 [P] 预测——private 会阻止什么

```java
class BankAccount {
    private double balance;

    BankAccount(double balance) {
        this.balance = balance;
    }

    void deposit(double amount) {
        if (amount > 0) {
            balance += amount;
        }
    }

    double getBalance() {
        return balance;
    }
}
```

预测：

1. 外部能写 `account.balance = 999` 吗？
2. `deposit(-100)` 会发生什么？
3. 外部如何读取余额？

---

## 6.3 [R] 运行——验证预测

```java
class Main {
    public static void main(String[] args) {
        BankAccount account = new BankAccount(100);
        account.deposit(50);
        System.out.println(account.getBalance());

        // account.balance = 999;  // 编译报错：balance has private access
    }
}
```

输出：

```
150
```

`private` 字段只能在本类内部直接访问，外部必须通过方法。
