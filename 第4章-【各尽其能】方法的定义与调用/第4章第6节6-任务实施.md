## 6.2 [I] 研究——方法由什么组成

看一个带返回值的示例方法：

```java
class Person {
    String name;
    int age;

    String greet(String language) {
        return "你好";
    }
}
```

拆解：

- `String greet(String language)`：返回类型是 String，方法名是 `greet`，参数是 `String language`
- `return "你好"`：把结果返回给调用者
- 参数是调用方法时传入的数据

方法可以返回数据，也可以使用 `void` 表示不返回。
