## 3.1 代码的执行顺序

计算机以怎样的顺序执行多行代码？

大多数情况下，代码的执行顺序是<font color="red">**「逐行」的、自上而下的**</font>（不考虑并发等特殊情况）。

以下述 Python 代码为例：

```python
a = 3
b = 5
print(a)  # 打印:3
print(b)  # 打印:5
print(a+b)  # 打印:8
```

只需要知道上述代码在执行的时候，是「逐行」执行的：从第 1 行开始依次执行到第 5 行，随后由于后续没有代码了，所以程序将退出。

但这只是程序执行的一种极其简单的情况。再看一个例子：

```python
a = 3
b = 5

def sample():
  print('Hello')

print('World')
```

上述代码会打印「Hello」和「World」吗？

如果是顺序执行，会先打印出「Hello」，再打印出「World」。

<font color="orange">**错**</font>。不会打印出「Hello」，只会打印出「World」。

这就很奇怪：明明第 5 行有 `print('Hello')` 但却不会打印出「Hello」。而第 7 行却可以打印出「World」？

只有一种情况可以解释这种现象：<font color="red">**第 5 行被 Python 跳过了，没有执行**</font>。

## 3.2 声明性语句与执行性语句

第 4 行和第 5 行是一个 Python 的函数（Python 的函数等同于 Java 的方法）。Python 用 `def` 关键字定义一个函数，用「缩进」来代替括号。第 5 行前面的空白就是「缩进」，第 5 行实际上是 `sample` 函数的函数体。

<font color="red">**函数不会按顺序立即执行**</font>。

绝大多数编程语言，并不是在任何时候都会「顺序逐行」执行。上述代码实际的执行顺序是：

```python
a = 3  # 第1步
b = 5  # 第2步

def sample():  # 跳过
  print('Hello')  # 跳过
  
print('World')  # 第3步
```

第 4 和第 5 行是在<font color="red">**声明一个函数**</font>，并不是「常规」代码，实际上被跳过了，并没有执行。

为什么会跳过「声明函数」这几行代码呢？

在 Python 中，可以将代码语句分为两大类：

<font color="blue">**声明性语句**</font>——用于定义程序结构但不立即执行操作

<font color="blue">**执行性语句**</font>——会立即执行产生效果

比如上述代码中：

```python
a = 3  # 执行性语句
b = 5  # 执行性语句

def sample():  # 声明性语句
  print('Hello')
  
print('World')  # 执行性语句
```

由于第 4 和第 5 行是在声明一个函数，所以程序在执行时会跳过这两行，直接执行第 7 行的代码。

这里要解释一下，说的「跳过」，并不是说程序完全忽略第 4 和第 5 行的声明函数语句。用简练的白话来说：

程序在执行到第 4 行时，会将第 4、5 行代码「标记」一下，就好像说：「我知道了，但我现在不执行」。随后程序会略过这两行，直接去继续执行第 7 行。

程序知晓这两行代码的存在是很重要的，这对于后面讲函数调用非常有用。

**总结一下**：<font color="red">所有执行性语句都会被顺序执行，而声明性语句会被「标记」，不会真的执行。</font>

## 3.3 Java 中的声明性代码

Java 的执行顺序大体上同 Python 类似。Java 的类和方法也具有声明语句的特性。只是用 Java 来讲解这个知识会更复杂不好理解，所以选择用 Python 来类比。

给一段 Java 代码，来表明哪些是声明性代码：

```java
// 类:声明性
class Cat {
    String name;
    int age;
    double weight;
        
    // 方法:声明性
    void feed(String foodName, int portions, Person person) {
        System.out.println(person.name + "正在喂" + portions + "份" + foodName);
    }
}
```

<font color="red">类定义和方法定义都是声明性语句，不会立即执行。</font>

## 3.4 方法的调用

现已明确类和方法属于声明性语句，并不会立即执行。问题来了：不能执行的代码写了干吗？

注意，说的是它不是「立即」执行。它们当然是可以执行的，只不过需要「调用」一下这个方法，它才能执行。

看下述代码：

```python
a = 3  # 执行性语句
b = 5  # 执行性语句

def sample():  # 声明性语句
  print('Hello')
  
print('World')  # 执行性语句
sample()  # 函数被调用,将打印出'Hello'
```

第 8 行代码就<font color="red">**调用**</font>了 `sample` 这个函数。

函数调用非常简单，只需要用 `函数名()` 这种语法即可。当函数被调用后，函数体里的代码就会被执行。所以上述代码最终除了打印出 `World` 之外，也会打印出 `Hello` 来。

上述代码的最终执行顺序为：

```python
a = 3  # 1
b = 5  # 2

def sample(): 
  print('Hello')  # 5
  
print('World')  # 3
sample()  # 4
```

当 `sample` 函数被调用时，程序将进入到函数内部开始执行函数体内部的代码，直到函数体内部的代码执行完成后，继续执行后续代码。

## 3.5 方法调用示例

Java 的方法调用和 Python 的函数调用一样，使用 `方法名()` 的方式调用：

```java
public class Main {
    public static void sample() {
        System.out.println(2);
        System.out.println(3);
    }

    // 主方法 - 程序入口
    public static void main(String[] args) {
        System.out.println(1);
        sample();
        System.out.println(4);
    }
}
```

上述代码同样会打印出 `1、2、3、4`。忽略一些还没有涉及的概念（如 `static` 关键字），只关心核心的「方法调用」：

1. 第 9 行打印数字 1
2. 第 10 行调用了预先定义的 `sample` 方法，这将执行 `sample` 方法体内部的第 3、4 行代码，打印数字 2 和 3
3. 当 `sample` 执行完成后，将执行第 11 行代码，打印数字 4

这个流程和 Python 是一模一样的。

## 3.6 在方法调用时传入参数

如何调用一个有参数的方法？

```java
public class Main {
    // 定义2个参数的方法
    public static void add(int a, int b) {
      System.out.println(a+b);
    }

    // 主方法 - 程序入口
    public static void main(String[] args) {
      add(1,2);  // 调用add方法,并传入参数值
    }
}
```

第 9 行调用了 `add` 方法，并传入了 2 个参数 `1` 和 `2`。

对于有参方法 `add`，只有知道 a 和 b 的值，才能计算 a+b 的值。在调用方法时，将参数的值输入到方法中：

```java
add(1,2);
```

这样，`add` 方法就知道了 `a=1` 和 `b=2`，最终将计算出 `a+b` 的值 `3`，并打印出来。

## 3.7 形参和实参的概念

方法的参数分为<font color="red">**形参**</font>和<font color="red">**实参**</font>：

- 在方法被定义时，参数列表中出现的参数，被称为<font color="blue">**形参**</font>。所有形参构成的参数列表称为**形参列表**。
- 当方法被调用时，实际传入到方法中的参数被称为<font color="blue">**实参**</font>。

看一段 Python 代码（Python 语法更简洁，便于理解）：

```python
c = 1
d = 2

# 函数定义
# a和b是函数的形参
def add(a, b): 
  print(a+b)

# 调用有参函数
add(c, d)  # 实参:c和d。结果打印:3
```

`a` 和 `b` 为**形参**，它们共同构成「形参列表」。当调用 `add` 函数时，将 `c` 和 `d` 传入到 `add` 函数中。此时，`c` 和 `d` 为调用 `add` 函数时输入的实际参数，简称**实参**。

<font color="red">**形参**</font>，即<font color="red">**形式参数**</font>。所谓形式，即表明它不是真实的参数，只是一种临时的「占位符」。它的作用是表明函数所需参数的个数、类型等信息。

再给出一段 Java 方法：

```java
void add(int a, int b) {
  System.out.println(a+b);
}
```

对于 `add` 方法，`a` 和 `b` 也是形参，它们的作用是表明：

> 「当我被调用时，请传给我 2 个 int 类型的数据。」

但形参不是真实的参数，真实参数（实参）是方法调用时传入的值：

```java
add(c, d);
// 或者
add(1, 2);
```

## 3.8 形参的作用与方法复用

已经了解了函数的形参是什么，但可能还没有深刻理解形参的意义。

看看这个 Python 函数：

```python
def add(a, b): 
  print(a+b)
```

当一个函数在被定义时，函数的形参值是<font color="red">**不确定**</font>的：

- 有可能是 `a=1`，`b=2`，则结果为 3
- 有可能是 `a=100`，`b=330`，则结果为 430
- 谁知道呢？

这是合理的。因为对于 `add` 函数，它的目的是计算**任意两个数字**的「和」。假如在函数定义时就给 `a=100`，`b=400` 这两个固定值，那么这个函数就只能计算 `a=100` 和 `b=400`，相加的结果为 500。

这没有意义。如果只是计算两个固定数值的和，完全不需要用到函数：

```python
print(100+400)
```

<font color="red">**方法（函数）的目的是为了根据不同的实参，来完成不同的行为或计算不同的数据**</font>：

```python
c = 1
d = 2
e = 3
f = 4

def add(a, b): 
  print(a+b)

add(c, d)  # 实参:c和d。结果打印:3
add(e, f)  # 实参:e和f。结果打印:7
add(f, c)  # 实参:f和c。结果打印:5
```

上述代码才展现了形参的意义。在定义函数 `add` 时，只知道需要将两个数相加，但不知道是哪两个数；但在函数调用时，这两个数将被确定。

这也是为什么在定义 `add` 函数时，只将 `a` 和 `b` 称为「形参」；但在函数调用时，将实际传入的数值称为「实参」——它实际地确定了参数真实值。

正是由于这种设计，让函数（方法）具有<font color="red">**可复用性**</font>——只需要让实参取不同的值，方法就可以计算出不同的数值或者完成不同的行为。

## 3.9 方法的封装与复用

方法最基础的作用是<font color="red">**复用**</font>（反复使用）。

要完成「做饭」这个行为，可能需要一些复杂的「组合行为」：

- 买菜
- 洗菜
- 切菜
- 炒菜

可以想象下，如果一个程序中需要做 10 次饭，可能会出现这样的繁琐代码：

```python
print("买菜")
print("洗菜")
print("切菜")
print("炒菜")
# ......
print("买菜")
print("洗菜")
print("切菜")
print("炒菜")
```

但有了函数，就可以将这些繁琐的行为封装在一个函数中：

```python
def cook():
  print("买菜")
  print("洗菜")
  print("切菜")
  print("炒菜")
```

每次需要做饭时只需要调用 `cook` 这个函数：

```python
cook()
cook()
# ......
cook()
```

这就是函数（方法）最基础的作用：<font color="red">**复用**</font>（反复使用）。将重复的逻辑封装在方法中，需要时调用即可，避免代码重复。
