## 2.1 认识多维数组

一维数组里的每个元素是基本类型或对象。当元素本身也是数组时，就形成了<font color="red">**多维数组**</font>。

最常见的多维数组是二维数组，可以把它看作一张表格——有行有列。Java 也支持更高维度的数组：

**二维数组**——包含多个一维数组的数组，类似表格的行与列

**三维数组**——包含多个二维数组的数组，可以想象成多张表格叠在一起

四维、五维甚至更高维度在理论上也存在，但实际开发中很少用到三维以上。

以二维数组为例，声明方式如下：

```java
// 标准方式(推荐)
int[][] matrix;        // 二维数组
double[][][] cube;     // 三维数组

// C风格声明(合法但不推荐)
int matrix[][];        // 二维数组
```

`int[][]` 的读法是「int 的二维数组」，两层方括号代表两个维度。推荐把方括号放在类型后面，而不是变量名后面，这样语义更清晰。

## 2.2 二维数组的初始化

### 静态初始化

声明的同时直接赋值，编译器自动推断各维度长度：

```java
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};
```

这创建了一个 2 行 3 列的二维数组。外层大括号包含两个元素，每个元素本身是一个包含三个整数的一维数组。

### 动态初始化

使用 `new` 关键字指定行数和列数：

```java
double[][] matrix = new double[3][4];  // 3行4列
```

这创建了一个 3 行 4 列的矩阵，所有元素自动赋默认值 `0.0`。

### 不规则数组

Java 的二维数组有一个独特之处：每一行的长度可以不同。这种数组称为<font color="blue">**不规则数组**</font>或<font color="blue">**锯齿数组**</font>：

```java
int[][] jagged = {
    {1},
    {2, 3},
    {4, 5, 6}
};
```

第一行只有 1 个元素，第二行有 2 个，第三行有 3 个。这种结构在某些特殊场景下很有用，比如存储金字塔形的数据。

不规则数组也可以动态创建，但需要分步进行：

```java
int[][] irregular = new int[3][];  // 先指定行数,列数留空
irregular[0] = new int[1];         // 第一行1列
irregular[1] = new int[2];         // 第二行2列
irregular[2] = new int[3];         // 第三行3列
```

## 2.3 多维数组的访问

二维数组通过两个索引来访问元素，第一个索引定位行，第二个索引定位列：

```java
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};

int value = grid[1][2];    // 6,获取第2行第3列的元素
grid[0][1] = 10;           // 将第1行第2列修改为10
```

三维数组则需要三个索引：

```java
int[][][] tensor = {
    {
        {1, 2},
        {3, 4}
    },
    {
        {5, 6},
        {7, 8}
    }
};

int v = tensor[0][1][0];   // 3,第一个平面第二行第一列
tensor[1][0][1] = 99;      // 修改第二个平面第一行第二列
```

`grid.length` 返回的是行数（外层数组的长度）。要获取某一行的列数，使用 `grid[i].length`：

```java
int rows = grid.length;       // 2,行数
int cols = grid[0].length;    // 3,第一行的列数
```

对于不规则数组，每一行的 `grid[i].length` 可能不同。

## 2.4 多维数组的遍历

n 维数组通常需要 n 层循环来遍历所有元素。二维数组用两层嵌套循环：

```java
int[][] grid = {
    {1, 2, 3},
    {4, 5, 6}
};

for (int i = 0; i < grid.length; i++) {
    for (int j = 0; j < grid[i].length; j++) {
        System.out.print(grid[i][j] + " ");
    }
    System.out.println();
}
```

输出结果：

```
1 2 3 
4 5 6 
```

外层循环遍历行，内层循环遍历每一行中的列。内层循环的条件使用 `grid[i].length` 而不是固定值，这样可以正确处理不规则数组。

增强 for 循环同样适用于多维数组：

```java
for (int[] row : grid) {
    for (int val : row) {
        System.out.print(val + " ");
    }
    System.out.println();
}
```

这种写法更简洁，不需要关心索引，直接拿到每个元素。

三维数组的遍历需要三层循环：

```java
int[][][] cube = {
    {{1, 2}, {3, 4}},
    {{5, 6}, {7, 8}}
};

for (int i = 0; i < cube.length; i++) {
    System.out.println("第" + (i + 1) + "个平面:");
    for (int j = 0; j < cube[i].length; j++) {
        for (int k = 0; k < cube[i][j].length; k++) {
            System.out.print(cube[i][j][k] + " ");
        }
        System.out.println();
    }
}
```
