## 6.2 [P] 预测——数组的初始状态

```java
class ArrayDemo {
    public static void main(String[] args) {
        int[] scores = {85, 90, 78};
        System.out.println("长度：" + scores.length);
        System.out.println("第一个：" + scores[0]);

        int[] numbers = new int[3];
        System.out.println("默认值：" + numbers[1]);
    }
}
```

预测：

1. `scores.length` 是多少？
2. `scores[0]` 是多少？数组下标从几开始？
3. `numbers[1]` 的默认值是多少？

---

## 6.3 [R] 运行——验证预测

```
长度：3
第一个：85
默认值：0
```

数组长度固定，下标从 0 开始。动态初始化会先给基本类型默认值。

## 6.4 [I] 研究——两种初始化方式

```java
// 静态初始化
int[] arr1 = {1, 2, 3};

// 动态初始化
int[] arr2 = new int[3];

// new 时同时赋值
int[] arr3 = new int[]{1, 2, 3};
```

思考：

- `arr2` 的默认值是什么？
- 为什么数组长度不能修改？
