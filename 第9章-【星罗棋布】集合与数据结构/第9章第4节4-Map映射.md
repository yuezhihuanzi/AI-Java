## 4.1 认识键值对

前面学过的数组、List、Set 都是存储「一组元素」的集合类型。如果要存储「名字和年龄」「商品和价格」这类成对出现的数据，就需要另一种数据结构。

<font color="blue">**Map**</font> 是 Java 提供的映射类型，用于存储<font color="red">**键值对**</font>（Key-Value）数据。在许多其他编程语言（Python、C#）中，这种类型称为「字典」。

理解键值对最直接的方式是把它类比为字典的行为：通过拼音（键）去查找对应的汉字（值）。每个键对应一个值，形成一对一的映射关系。

Map 对键值对有一些明确的规则：

<font color="orange">**键唯一**</font>——每个键最多只能映射到一个值，不允许重复的键

<font color="orange">**值可重复**</font>——不同的键可以映射到相同的值

```
姜磺: 8岁
姜磺: 6岁
// 键"姜磺"重复了,这是不被允许的

姜磺: 8岁
小满: 8岁
// 键不同,值相同是允许的
```

第二次用相同的键存入时，新值会覆盖旧值。

与之前的集合类型一样，Map 也不能直接使用。以下是常见的实现类：

**HashMap**——基于哈希表实现，使用最多

**LinkedHashMap**——在 HashMap 基础上维护插入顺序

**TreeMap**——基于红黑树实现，键按自然顺序排序

**ConcurrentHashMap**——线程安全的 Map

下面以 `HashMap` 为例讲解 Map 的用法。

## 4.2 HashMap 的基本操作

使用 HashMap 需要导入对应的包：

```java
import java.util.HashMap;

class Main {
    public static void main(String[] args) {
        HashMap map = new HashMap();

        // 添加/更新元素
        map.put("Java", 1);
        map.put("Python", 2);
        map.put("Java", 3);    // 更新"Java"对应的值

        // 获取元素
        Integer value = (Integer) map.get("Java");     // 3
        value = (Integer) map.get("C++");              // 键不存在,返回null

        // 删除元素
        Integer removed = (Integer) map.remove("Python");  // 返回被删除的值2

        // 检查键/值是否存在
        boolean hasKey = map.containsKey("Java");      // true
        boolean hasValue = map.containsValue(3);       // true

        // 获取Map信息
        int size = map.size();                         // 键值对数量
        boolean empty = map.isEmpty();                 // 是否为空
    }
}
```

`put` 方法用于添加或更新键值对。如果键已存在，新值会替换旧值；如果键不存在，则创建新的映射。

`get` 方法通过键获取对应的值。如果键不存在，返回 `null`。

由于没有使用泛型，获取的值是 `Object` 类型，需要强制转型为具体类型（如 `(Integer)`）。

## 4.3 获取所有键和所有值

Map 存储的是键值对，可以通过内置方法分别获取所有键的集合和所有值的集合：

```java
import java.util.HashMap;
import java.util.Set;
import java.util.Collection;

class Main {
    public static void main(String[] args) {
        HashMap map = new HashMap();
        map.put("Java", 1);
        map.put("Python", 2);
        map.put("C#", 3);

        // 获取所有键的集合
        Set keys = map.keySet();       // 包含: Java, Python, C#

        // 获取所有值的集合
        Collection values = map.values();  // 包含: 1, 2, 3
    }
}
```

`keySet()` 返回所有键组成的 Set 集合（因为键本身不可重复）。`values()` 返回所有值组成的 Collection 集合。

返回的 Set 和 Collection 都可以用循环遍历：

```java
// 遍历所有的键
for (Object k : keys) {
    System.out.println(k.toString());
}

// 遍历所有的值
for (Object v : values) {
    System.out.println(v.toString());
}
```

如果既要访问键又要访问值，可以遍历键集合，再通过键获取对应的值：

```java
for (Object k : map.keySet()) {
    System.out.println(k.toString() + " -> " + map.get(k).toString());
}
```
