## 6.2 [P] 预测——子类能调用父类方法吗

```java
class Creature {
    protected String name;
    protected int hp;

    Creature(String name, int hp) {
        this.name = name;
        this.hp = hp;
    }

    boolean isAlive() {
        return hp > 0;
    }
}

class Player extends Creature {
    Player(String name, int hp) {
        super(name, hp);
    }
}

class Main {
    public static void main(String[] args) {
        Player hero = new Player("姜磺", 100);
        System.out.println(hero.isAlive());
        System.out.println(hero.name);
    }
}
```

预测：
1. `Player` 没有定义 `isAlive()`，能调用吗？
2. `super(name, hp)` 的作用是什么？
3. `hero.name` 能访问吗？为什么？
