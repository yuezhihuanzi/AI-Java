## 5.1 继承真的是代码复用吗

<font color="red">**问**</font>：老师，书上说继承的主要目的是"代码复用"。但我总觉得这个说法有问题。

<font color="red">**答**</font>：你的直觉很好。继承确实有复用的效果，但"复用"不是继承最核心的价值。

<font color="red">**问**</font>：那什么才是？

<font color="red">**答**</font>：继承的核心价值是<font color="red">**建立类型之间的关系**</font>。

```java
class Animal {
    void eat() { }
}

class Cat extends Animal { }
class Dog extends Animal { }
```

<font color="red">**问**</font>：Cat和Dog都继承了eat(),这不是复用吗？

<font color="red">**答**</font>：是复用的效果，但建立关系才是目的。因为有了这个关系，你才能写出这样的代码：

```java
void feed(Animal animal) {
    animal.eat();  // 不管来的是猫还是狗,都能正确处理
}
```

<font color="red">**问**</font>：如果没有继承关系，这段代码就写不出来？

<font color="red">**答**</font>：对。没有继承，Cat和Dog就是两个完全无关的类型，你无法用一个统一的方法来处理它们。

> 复用是继承的副产品，建立类型关系才是继承的核心目的。

<font color="red">**问**</font>：那如果纯粹为了复用，不用继承用什么？

<font color="red">**答**</font>：组合。把一个类的对象作为另一个类的成员变量，也能复用它的功能，而且耦合度更低。现代Java设计更推荐"组合优于继承"。

## 5.2 为什么重写equals就必须重写hashCode

<font color="red">**问**</font>：老师，我不理解，为什么重写了equals(),就必须重写hashCode()?

<font color="red">**答**</font>：看一个场景：

```java
Set<Student> set = new HashSet<>();
Student s1 = new Student("John", 20);
Student s2 = new Student("John", 20);
// 假设改写了equals(),name和age相同就认为相等
set.add(s1);
boolean contains = set.contains(s2); // 可能返回false!
```

<font color="red">**问**</font>：s1和s2相等，但contains却返回false?

<font color="red">**答**</font>：对。因为`HashSet`查找对象时，先用`hashCode()`定位大致区域，再用`equals()`精确确认。如果两个对象`equals`相等，但`hashCode`不同，`HashSet`就会在错误的区域找，根本找不到。

<font color="red">**问**</font>：这就像...两本完全一样的书，被放到了图书馆完全不同的两个区域？

<font color="red">**答**</font>：很形象的比喻。邮政编码相同不代表地址相同，但地址相同邮编必须相同。`hashCode`就像邮政编码，`equals`就像详细地址。

## 5.3 super和this到底什么区别

<font color="red">**问**</font>：老师，super和this总是把我搞晕。

<font color="red">**答**</font>：记住一个核心：

> <font color="red">**this指向"当前对象",super指向"父类部分"。**</font>

```java
class Animal {
    String sound = "Animal sound";
}

class Cat extends Animal {
    String sound = "Meow";

    void makeSound() {
        System.out.println(this.sound);   // 输出: "Meow"
        System.out.println(super.sound);  // 输出: "Animal sound"
    }
}
```

<font color="red">**问**</font>：同一个Cat对象，怎么会有两个sound?

<font color="red">**答**</font>：Cat对象内部确实有两份sound。一份继承自Animal,一份是Cat自己定义的。`this.sound`访问的是Cat自己的，`super.sound`访问的是从Animal继承来的。

<font color="red">**问**</font>：那构造函数里的super()呢？

<font color="red">**答**</font>：`super()`是调用父类的构造函数，用来初始化从父类继承来的那部分状态。一个完整的对象 = 父类部分 + 自己定义的部分，`super()`负责初始化"父类部分"。
