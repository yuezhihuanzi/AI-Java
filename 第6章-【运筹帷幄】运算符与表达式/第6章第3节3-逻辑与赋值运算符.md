## 3.1 逻辑运算符

所谓逻辑运算，指的是布尔值之间的运算。Java 提供了 6 种逻辑运算符，专门用于处理布尔值（`true`/`false`）之间的运算：

| 运算符 | 名称 | 类型 | 描述 | 示例 |
|--------|------|------|------|------|
| `&&` | 短路与 | 二元 | 两操作数都为 true 时返回 true | `true && false = false` |
| `\|\|` | 短路或 | 二元 | 任一操作数为 true 时返回 true | `true \|\| false = true` |
| `!` | 逻辑非 | 一元 | 反转操作数的逻辑状态 | `!true = false` |
| `&` | 非短路与 | 二元 | 执行完整与运算，无短路行为 | `true & false = false` |
| `\|` | 非短路或 | 二元 | 执行完整或运算，无短路行为 | `true \| false = true` |
| `^` | 逻辑异或 | 二元 | 操作数不同时返回 true | `true ^ false = true` |

表中的「类型」一项表明当前运算符需要几个操作数：

- 一元只需要 1 个，比如 `!` 逻辑非操作符：`!true`
- 二元需要 2 个，比如：`true && false`，操作符 `&&` 左右各需要 1 个操作数

其实每个逻辑运算符的意义都非常清晰，操作符主要分为三种：与、或、非。分别对应中文里的三种逻辑：并且、或者、反转。如果对应英文，则分别对应：and、or、not。

- **`&&`**：并且的意思。只有两个操作数都为 `true` 时（A 并且 B 都为 `true`），整个运算结果才为 `true`。
- **`||`**：或者的意思。只要有一个操作数为 `true`（A 或者 B 是 `true`），整个运算结果才为 `true`。
- **`!`**：反转或者否定的意思。反转当前操作数的状态，即 `true` 变为 `false`，`false` 变为 `true`。
- **`^`**：异或操作符。当两个操作数不同时，返回 `true`，否则返回 `false`。
- **`&`、`|`**：意思同 `&&`、`||` 操作符基本相似，也表示「且」和「或者」的意思。但区别在于 `&`、`|` 是非短路的，而 `&&` 和 `||` 是短路的。

这里需要解释下什么是短路操作，什么是非短路操作。

### 短路

<font color="blue">短路（Short-Circuiting）</font>是编程语言中逻辑运算符（`&&` 和 `||`）的一种优化行为：当根据第一个操作数就能确定整个表达式的结果时，跳过对第二个操作数的求值。

**1. 短路与 (`&&`) 的行为**

| 第一个操作数 | 第二个操作数 | 是否求值第二个操作数 | 表达式结果 |
|-------------|-------------|-------------------|-----------|
| false | 任意值 | 否 | false |
| true | 任意值 | 是 | 取决于第二个操作数 |

原理：如果第一个操作数已经是 `false`，无论第二个操作数是什么，整个 `&&` 表达式都必定是 `false`。

**2. 短路或 (`||`) 的行为**

| 第一个操作数 | 第二个操作数 | 是否求值第二个操作数 | 表达式结果 |
|-------------|-------------|-------------------|-----------|
| true | 任意值 | 否 | true |
| false | 任意值 | 是 | 取决于第二个操作数 |

原理：如果第一个操作数已经是 `true`，无论第二个操作数是什么，整个 `||` 表达式都必定是 `true`。

短路特性对于 Java 来说非常重要，其主要原因在于短路可以避免对第二个操作数求值。

```java
false && true
```

上述表达式会触发短路机制。因为 Java 的 `&&` 是短路运算符（Short-Circuit Operator），一旦左侧结果为 `false`，右侧操作数不会被计算（直接跳过）。如果你想避免短路这种特性，可以使用 `&`（非短路）运算符：

```java
false & true // 不会触发短路机制
```

看起来上面的短路案例好像并没有什么意义。但之所以你认为没有意义是因为上述案例只是为了方便同学们理解短路，并不具有实际意义。再来看一个示例：

```java
isValid() && queryDatabase() // 当第一个条件失败时，跳过耗时的数据库查询
```

上述逻辑运算由两个方法调用构成。第一个是 `isValid()` 判断是否合法，第二个 `queryDatabase()` 会查询数据库。查询数据库是一个非常耗时的操作。那么这里短路特性有什么作用？

如果 `isValid()` 为 `false`，表明不合法，这个时候其实已经没有必要执行后续的查询数据库方法了。由于 `&&` 短路的特性，这就避免了 `queryDatabase()` 的执行，节约了计算机的性能。

但如果没有短路，无论 `isValid()` 是否合法，都会执行 `queryDatabase()`，这就浪费了计算机的性能。

短路的特性还有其他很多的应用，比如可以避免空指针问题等。同学们可以在未来学习工作中慢慢体会。

### 非短路

在理解短路后，非短路符号 `&` 和 `|` 就简单很多了。非短路意味着无论操作数是 `true` 还是 `false`，都会将所有的表达式计算一遍。

```java
false & true // 不会触发短路机制，需要判断左右两个操作数
true | false // 不会触发短路机制，需要判断左右两个操作数
```

最后需要提醒同学们，<font color="red">**逻辑运算的操作数必须是布尔类型，不能是任何其他类型**</font>。比如下面就是错误的：

```java
true && 1
```

上述表达式在其他语言里可能是正确的（有些语言会将 `1` 视为 `true`），但在 Java 里这是不对的，因为右侧操作数不是布尔类型，所以 Java 在编译时会出现错误。

### 真值表

下表给出了 A 和 B 两个操作数所有可能的逻辑运算结果，建议同学们不用死记硬背，但可以通过这个表找一下规律。

| A | B | A && B | A \|\| B | A & B | A \| B | A ^ B | !A |
|------|------|---------|----------|--------|--------|--------|-----|
| true | true | true | true | true | true | false | false |
| true | false | false | true | false | true | true | false |
| false | true | false | true | false | true | true | true |
| false | false | false | false | false | false | false | true |

## 3.2 位运算符

位运算符是直接操作整数类型（`byte`、`short`、`int`、`long`、`char`）二进制位的运算符。它们在底层编程、性能优化和特定算法中扮演着关键角色。

什么叫做「整数类型二进制位」？任何数字都可以用我们最熟悉的 10 进制来表示，也可以用 2 进制来表示。而位运算符是操作数字的 2 进制形式，而非操作 10 进制形式。

以位运算符 `~` 举例，`~` 按位取反操作符：

```java
int a = 5;        
int b = ~a;      
System.out.println(b); // 输出: -6
```

为什么 `~a` 的值是 -6？

它是这样得出来的：

```java
int a = 5;       // 二进制: 00000101
int b = ~a;      // 对00000101的每一位取反-> 11111010 -> -6
System.out.println(b); // 输出: -6
```

「取反」意味着 0→1，1→0，这样 `00000101` 取反后得到一个新的 2 进制数 `11111010`，然后再换算成 10 进制，得到 -6。

所有的位运算符都是对 2 进制数进行相应的运算：

| 运算符 | 名称 | 类型 | 描述 | 示例 | 结果 |
|--------|------|------|------|------|------|
| `~` | 按位取反 | 一元 | 翻转所有位（0 变 1，1 变 0） | `~5` | -6 |
| `&` | 按位与 | 二元 | 两位都为 1 时结果为 1 | `5 & 3` | 1 |
| `\|` | 按位或 | 二元 | 任意一位为 1 时结果为 1 | `5\|3` | 7 |
| `^` | 按位异或 | 二元 | 两位不同时结果为 1 | `5 ^ 3` | 6 |
| `<<` | 左移 | 二元 | 向左移位，低位补 0 | `5 << 1` | 10 |
| `>>` | 带符号右移 | 二元 | 向右移位，高位补符号位 | `-5 >> 1` | -3 |
| `>>>` | 无符号右移 | 二元 | 向右移位，高位补 0 | `-5 >>> 1` | 2147483645 |

上述表中又一次出现了 `|` 和 `&` 运算符，这两个运算符在逻辑运算符中也出现过。

`|` 和 `&` 在 Java 中具有多义性，既可以表示逻辑运算中的「非短路与」和「非短路或」运算，也可以在位运算中表示「按位与」和「按位或」。具体是哪种运算，取决于操作数是布尔类型还是整数类型。

### 位运算的意义

位运算由于其运算过程不是那么直接，且不容易理解，所以长期被程序员忽视。很多程序员搞不清楚为什么要用位运算操作整数的 2 进制形式，而不是直接对 10 进制形式进行操作。

这里非常重要的原因是：<font color="red">**计算机本身就是 2 进制的，它只能存储 0 和 1。所以直接操作 0 和 1 这两个数字的效率远比操作其他数字要快很多。**</font>

比如对一个数乘以或者除以：

```java
// 乘以8 (2³)
int a = 7 * 8; // 56
// 除以4(2²)
int b = 20 / 4; // 5
```

可以优化为位运算：

```java
// 乘以8 (2³)
int multiply = 7 << 3; // 56
// 除以4 (2²)
int divide = 20 >> 2; // 5
```

同样的结果，但位运算属于计算机偏底层的运算，所以速度比直接操作 10 进制数要快很多。这在进行海量运算时对计算速度的提升至关重要。

## 3.3 赋值运算符

赋值运算符其实我们在之前的章节中已经反复使用过了。

赋值运算符是 Java 中最基础也最常用的运算符，用于将值赋给变量。除了基本的 `=` 运算符外，Java 还提供了多种复合赋值运算符，可简化表达式并提高代码效率。

### 基本赋值运算符 =

`=` 号是最基本的赋值运算符。它将右侧操作数的值赋给左侧变量。

```java
int x = 10;        // 直接赋值
int y = x + 5;     // 表达式赋值
String name = "Java"; 
Cat cat = new Cat(); // 对象赋值
```

要特别注意，`=` 号的右侧也可以是一个表达式，因为我们之前讨论过，表达式无论多复杂，最终都需要返回一个值，所以等同于将值赋值给变量。

### 复合赋值运算符

除了基本赋值运算符，Java 提供了 11 种复合赋值运算符，将算术或位运算与赋值结合：

| 运算符 | 名称 | 描述 | 示例 | 等价形式 |
|--------|------|------|------|---------|
| `+=` | 加法赋值 | `a += b` → `a = a + b` | `a += 3;` | `a = a + 3;` |
| `-=` | 减法赋值 | `a -= b` → `a = a - b` | `a -= 2;` | `a = a - 2;` |
| `*=` | 乘法赋值 | `a *= b` → `a = a * b` | `a *= 4;` | `a = a * 4;` |
| `/=` | 除法赋值 | `a /= b` → `a = a / b` | `a /= 2;` | `a = a / 2;` |
| `%=` | 取模赋值 | `a %= b` → `a = a % b` | `a %= 3;` | `a = a % 3;` |
| `&=` | 按位与赋值 | `a &= b` → `a = a & b` | `a &= 3;` | `a = a & 3;` |
| `\|=` | 按位或赋值 | `a\|=b` → `a=a\|b` | `a \|=3;` | `a = a\| 3;` |
| `^=` | 按位异或赋值 | `a ^= b` → `a = a ^ b` | `a ^= 3;` | `a = a ^ 3;` |
| `<<=` | 左移赋值 | `a <<= b` → `a = a << b` | `a <<= 2;` | `a = a << 2;` |
| `>>=` | 带符号右移赋值 | `a >>= b` → `a = a >> b` | `a >>= 1;` | `a = a >> 1;` |
| `>>>=` | 无符号右移赋值 | `a >>>= b` → `a = a >>> b` | `a >>>= 3;` | `a = a >>> 3;` |

复合赋值运算符看起来挺多，但它们其实都遵循同一类运算规则，只要理解其中一种，其他的都是一样。

复合赋值运算符其实是一种简写，比如：

```java
int a = 2;
a += 3; // 等同于a=a+3
a &= 2; // 等同于 a=a&2
```

所有 11 种复合赋值运算符都是以上这种赋值和运算的 2 合 1 简写。

下面谈谈复合赋值运算有什么特点，概括起来有以下 3 个特点：

**复合赋值运算代码更简洁**

```java
double money = 100;
money *= 1.05; // 更简洁
money = money * 1.05; 
```

**复合赋值在效率和空间利用率上比普通赋值性能更好**

**复合赋值可以自动转换类型**

```java
byte b = 5;
b = b + 2;         // 错误，byte类型的b和int类型的2类型不同
b = (byte)(b + 2); // 需要显式转换
b += 2;            // 复合赋值（自动转换）
```

## 3.4 其他特殊运算符

Java 还提供了一些诸如自增（`++`），自减（`--`），三元运算等操作符。

### 自增、自减运算符

自增 (`++`) 和自减 (`--`) 是 Java 中最常用的单目（一元）运算符，用于对变量进行加 1 或减 1 操作。它们在循环控制和计数器操作中尤为重要。`++` 和 `--` 操作符又分为前缀和后缀：

| 运算符 | 位置 | 示例 | 名称 | 行为描述 |
|--------|------|------|------|---------|
| `++` | 前缀 | `++i` | 前自增 | 先加 1，后使用值 |
| `++` | 后缀 | `i++` | 后自增 | 先使用值，后加 1 |
| `--` | 前缀 | `--i` | 前自减 | 先减 1，后使用值 |
| `--` | 后缀 | `i--` | 后自减 | 先使用值，后减 1 |

前缀与后缀运算符最大的区别在于：前缀（`++i`、`--i`）变量先变化，后返回值；后缀（`i++`、`i--`）先返回原值，后变化变量。看看具体示例：

```java
int a = 5;

// 前自增
int b = ++a;  // ++是前缀，所以a先+1，再返回值。最终a=6, b=6

// 后自增
int c = a++;  // ++是后缀，所以先返回6，再让a+1。最终 a=7, c=6

// 前自减
int d = --a;  // a=6, d=6

// 后自减
int e = a--;  // a=5, e=6
```

### 三元运算符

Java 中仅有一个三元运算符 (`? :`)。它是一个非常简洁的条件表达式，由 3 部分构成，运算的最终结果取决于条件是否成立。语法结构：

```java
条件 ? 表达式1 : 表达式2
```

**执行流程**

- **评估条件**：首先计算条件的值（条件它必须是一个布尔表达式，结果为 `true` 或 `false`）。
- **选择分支**：
  - 如果条件为 `true`，则计算并返回表达式 1 的值。
  - 如果条件为 `false`，则计算并返回表达式 2 的值。

```java
int score = 85;
String result = (score >= 60) ? "及格" : "不及格"; // result将被赋值为 "及格"
System.out.println(result); // 输出: 及格
```

上述代码首先判断 `score>=60` 是否是 `true`。如果是 `true`，则返回「及格」，否则返回「不及格」。
