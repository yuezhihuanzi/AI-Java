## 6.2 [P] 预测——伤害是多少

任务公式：`伤害 = 攻击力 × 技能倍率 - 敌方防御`

```java
class BattleDemo {
    public static void main(String[] args) {
        int attack = 12;
        double skillMultiplier = 1.5;
        int enemyDefense = 2;

        int damage = (int) (attack * skillMultiplier) - enemyDefense;
        System.out.println("伤害值：" + damage);

        int enemyHp = 30;
        enemyHp -= damage;
        System.out.println("敌人剩余HP：" + enemyHp);

        boolean defeated = enemyHp <= 0;
        System.out.println("敌人被击败：" + defeated);
    }
}
```

先预测：

1. `attack * skillMultiplier` 的值是多少？它是什么类型？
2. `(int)(attack * skillMultiplier)` 的值是多少？
3. `damage` 最终是多少？
4. `enemyHp -= damage` 后等于多少？
5. `defeated` 是 `true` 还是 `false`？

## 6.3 [R] 运行——验证预测

运行上面的代码：

```text

```

- `(int)` 会把 `double` 截成 `int`
