## 4.1 运算符优先级

对于下述代码：

```java
int a = 1 + 1 * 2;
```

我们都知道它的顺序是，首先执行乘法，随后执行加法。这是我们从小学就已经了解的算术运算顺序，乘法的优先级高于加法。

但在 Java 中除了我们熟悉的算术符号优先级，还有很多诸如逻辑运算、关系运算参与在表达式计算中。比如你知道下述代码的运行结果吗：

```java
boolean flag = 5 > 3 && 4 < 2 || 3 == 3;
```

如果不熟悉 Java 运算符的<font color="blue">优先级</font>与<font color="blue">结合性</font>，我们很难判断出上述代码的运行结果。下表给出了 Java 常见运算符的优先级和结合性：

| 优先级 | 运算符类型 | 运算符 | 结合性 |
|--------|-----------|--------|--------|
| 1 | 后缀运算符 | `expr++` `expr--` | 左到右 |
| 2 | 前缀运算符 | `++expr` `--expr` `+expr` `-expr` `~` `!` | 右到左 |
| 3 | 乘除模 | `*` `/` `%` | 左到右 |
| 4 | 加减 | `+` `-` | 左到右 |
| 5 | 移位 | `<<` `>>` `>>>` | 左到右 |
| 6 | 关系 | `<` `<=` `>` `>=` `instanceof` | 左到右 |
| 7 | 相等 | `==` `!=` | 左到右 |
| 8 | 位与 | `&` | 左到右 |
| 9 | 位异或 | `^` | 左到右 |
| 10 | 位或 | `\|` | 左到右 |
| 11 | 逻辑与 | `&&` | 左到右 |
| 12 | 逻辑或 | `\|\|` | 左到右 |
| 13 | 三元条件 | `? :` | 右到左 |
| 14 | 赋值 | `=` `+=` `-=` `*=` `/=` `%=` `&=` `^=` `\|=` `<<=` `>>=` `>>>=` | 右到左 |

对于这张表，不要死记硬背，大概记住一些常用的、关键的运算符的优先级即可。也不要去背诵每个符号的具体级别数字，比如「逻辑或 `||`」优先级为 12，这是没有必要的也很难记住的。

建议大致记住常用运算符的优先级是高是低即可。比如：

- 一元运算符优先级最高
- 常用的算术运算符优先级其次
- 关系运算符优先级中等
- 逻辑运算符优先级非常低
- 赋值运算符优先级最低

> **提示**  
> 位运算符在常规编程里用的不多，可以用到时再去了解。

来分析下示例代码的优先级顺序：

```java
boolean flag = 5 > 3 && 4 < 2 || 3 == 3;
// 等价于：((5>3) && (4<2)) || (3==3)
// 5>3=true, 4<2=false → true&&false=false
// false || true = true
```

关系运算符优先级较高，所以会先计算 `5>3`、`4<2` 和 `3==3`。

随后才会计算逻辑运算。

括号可以强制改变优先级：

```java
int a = 3 + 2 * 5;
int b = (3 + 2) * 5; // 优先计算括号里的加法
```

### 常见错误

有时候同一种类型的运算符，优先级别并不一样，比如 `&&` 和 `||` 同为逻辑运算符，但实际上 <font color="orange">`&&` 优先级高于 `||`</font>：

```java
boolean error = 5 > 3 || 4 < 2 && 3 == 3; 
// 等价于 (5>3) || ((4<2) && (3==3)) → true || (false && true) → true
// 错误：(5>3 || 4<2) && (3==3) → true
```

`&&` 会优于 `||` 先计算。

```java
int k = 5;
k *= 2 + 3;   // 等价于 k = k * (2+3) = 25，不是 (k*2)+3=13
```

`+` 号运算符高于赋值运算符 `*=`。

### 最佳实践

<font color="red">**括号优先原则**</font>：复杂表达式使用括号明确优先级。

```java
// 不推荐
boolean r = a & MASK == FLAG || b < MIN && c > MAX;

// 推荐
boolean r1 = ((a & MASK) == FLAG) || ((b < MIN) && (c > MAX));
```

有时候，如果表达式过于复杂，建议使用 `()` 强制标出优先级，这样我们在阅读代码的时候就不需要动脑筋去了解运算符优先级，直接按括号顺序理解即可。

可以将复杂表达式拆分：

```java
// 不推荐
int result = (a * b) + (c << d) - (e % f);

// 推荐
int temp1 = a * b;
int temp2 = c << d;
int temp3 = e % f;
int result = temp1 + temp2 - temp3;
```

太复杂的表达式，可以分步骤来计算。

总之，如果一个表达式过于复杂，考虑到代码的良好阅读性，应该想办法简化。
