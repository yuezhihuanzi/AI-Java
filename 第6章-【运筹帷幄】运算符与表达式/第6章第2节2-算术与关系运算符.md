## 2.1 主要运算符与分类

Java 常见的运算符如下表所示：

| 类别 | 运算符示例 | 主要用途 |
|------|-----------|---------|
| 算术运算符 | `+` `-` `*` `/` `%` | 数学计算 |
| 关系运算符 | `==` `!=` `>` `<` `>=` `<=` | 比较操作 |
| 逻辑运算符 | `&&` `\|\|` `!` | 布尔逻辑 |
| 位运算符 | `&` `\|` `^` `~` `<<` `>>` | 位级操作 |
| 赋值运算符 | `=` `+=` `-=` `*=` `/=` | 赋值操作 |
| 其他运算符 | `?:` `instanceof` `++` `--` | 特殊操作 |

除了上表中的类别分类，我们还可以按照参与运算的操作数数量来分类：

- **一元运算符**：操作一个操作数（如 `++` 运算符：`++i`）
- **二元运算符**：操作两个操作数（如 `+` 运算符：`1+1`）
- **三元运算符**：操作三个操作数（仅条件运算符 `?:`）

## 2.2 算术运算符

算术运算符是数学中常见的运算符。

```java
int a = 10, b = 3;

int c = a + b;  // c=13 (加法)
int d = a - b;  // d=7  (减法)
int e = a * b;  // e=30 (乘法)
int f = a / b;  // f=3  (整数除法)
int g = a % b;  // g=1  (取模：求余数)
```

算术运算符均属于二元运算符，因为它需要两个操作数。在以上运算中，我们需要特别讲一下「除法」操作。

### 除法运算

```java
int a = 10 / 4;  // a=2.5?
```

在数学里，我们会认为 10÷4=2.5。但在 Java 中，`10/4` 结果不是 2.5，而是整数 2。

<font color="red">**当除法的两个操作数均为整数时，Java 执行整数除法，其结果必定是整数（舍去小数位，不四舍五入）。**</font>

```java
int a = 10 / 4;  // a=2
int b = 7 / 3;   // b=2
```

那么如何能够保留小数？

<font color="red">**至少有一个操作数是浮点数时，Java 执行浮点数除法，结果是浮点数（`double` 或者 `float` 类型）。**</font>

```java
double a = 10.0 / 4;  // a=2.5
float b = 7f / 3f;    // b=2.3333333
```

### 取模运算

取模运算（`%`）返回除法后的余数。

```java
int a = 10 % 3;   // a=1 (10 ÷ 3 = 3 余 1)
int b = 15 % 4;   // b=3
int c = 8 % 2;    // c=0 (整除)

// 负数的取模运算
int d = 10 % -3;   // d=1
int e = -10 % 3;   // e=-1
int f = -10 % -3;  // f=-1
```

一些常见的取模运算的场景：

```java
// 判断某数是奇数还是偶数
boolean isEven = (number % 2 == 0);

// 分钟转小时+分钟
int totalMinutes = 125;
int hours = totalMinutes / 60;     // hours = 2
int minutes = totalMinutes % 60;   // minutes = 5
```

## 2.3 自动类型提升

Java 在常见的算术运算中，存在一个结果到底是什么类型的问题：

```java
int a = 1;
int b = 2;
int c = a + b; // 两个int相加结果还是int c = 3

// 但如果1个double和1个int相加结果是什么类型？
// 是double还是int？
double d = 3.0;
int e = 2;
double f = e + d;  // 结果是double类型 f = 5.0
```

怎么解释上述的情况，为什么 1 个 `double` 和 1 个 `int` 相加得到的结果是 `double` 类型？如果是 1 个 `float` 和 1 个 `double` 相加得到的又是什么类型？这里有没有什么规律？

Java 存在一种叫做「<font color="blue">自动类型提升</font>」的机制可以帮助我们推测结果的类型。

<font color="blue">**自动类型提升（Implicit Type Promotion）**</font>是 Java 在表达式计算中自动将较小数据类型转换为较大数据类型的过程。这种转换是隐式的，不需要程序员显式指定。

比如：

```java
double d = 3.0;
int e = 2;
double f = e + d;  // 结果是double类型 f = 5.0
```

为什么上述 `f` 的结果是 `double` 而不是 `int`？因为 `double` 类型比 `int` 类型精度和数据容量都要大，那么 Java 就倾向于最终结果是 `double` 类型。这个决定过程是 Java 自己决定的，所以它是「隐式」的，不需要我们显式地指定类型。再来看一个例子：

```java
byte b = 100;
short s = 50;

// 所有操作数提升为int
int result1 = b + s;     // 100 + 50 = 150 (int)
```

请问 1 个 `byte` 和 1 个 `short` 相加得到的结果类型是什么？答案是 `int` 类型。因为 `int` 类型能表达的数据容量更大。这也是自动类型提升机制在起作用。

自动类型提升，「自动」指结果类型由 Java 自动决定；「提升」，指运算结果的类型往往会往数据容量更大、精度更高的类型靠拢。

自动类型提升存在以下规律：

- 所有 `byte`、`short` 和 `char` 会提升为 `int`
- 如果操作数中有 `long`，结果提升为 `long`
- 如果操作数中有 `float`，结果提升为 `float`
- 如果操作数中有 `double`，结果提升为 `double`

这里我们可以简单地谈一下，为什么 Java 会有这种自动提升机制：<font color="red">**为了防止数值溢出和精度丢失**</font>。

比如两个 `short` 类型的数值运算后，可能会超过 `short` 类型的最大容量，所以 Java 会将结果提升为 `int`。当然，这种自动提升机制只能在一定程度上缓解这些问题，要完全杜绝溢出和精度丢失，还是需要程序员自行判断运算结果的数值和精度。

## 2.4 类型转换

Java 在没有人为干预的时候，会执行自动类型提升。但有时候，自动类型提升并不符合我们的要求，比如：

```java
float d = 3.0f;
int e = 2;
float f = e + d;  // 结果是float类型 f = 5.0
```

根据 Java 的类型自动提升，可知默认情况，结果 `f` 将被提升为 `float` 类型。上述代码也确实将 `f` 定义为了 `float` 类型。

但如果我们想让结果 `f` 的类型是其他类型呢？比如，`f` 可不可以是 `int` 类型，可不可以是 `double` 类型？Java 必须要有某种机制，可以让用户自由决定数值的类型。这种机制就是**类型转换**。

在 Java 中类型转换分为隐式类型转换和显式类型转换。

### 隐式转换（Implicit Conversion / Widening）

由 Java 编译器自动完成，无需程序员干预，发生在小类型向大类型转换时（保证精度不丢失）。

```text
byte → short → int → long → float → double
char → int → long → float → double
```

```java
int a = 100;
long b = a;      // int → long（隐式转换）

double e = 3.14f; // float → double（隐式转换）
```

可以看到，上述代码都是由容量较小的类型自动转换到容量较大的类型。这个过程不需要特别的操作。但如果我们尝试将大类型转向小类型，这是不能隐式转换的，Java 编译器会报错。

```java
float e = 3.14d; // 报错
```

上述代码尝试将大类型 `double` 转换为小类型 `float`，这是不能自动隐式转换的。大类型转换为小类型是有可能发生数值截断从而造成数据丢失，所以这个过程不能由编译器自动完成。比如：

```java
int i = 200;
byte b = (byte) i;   // int → byte（b=-56）
```

上述代码将 `int` 强制转换为 `byte` 类型，由于 `byte` 类型装不下 `int`（`byte` 范围 -128 到 127），所以这就会将数据截断，得到 -56 这个值。

### 显式转换（Explicit Conversion / Narrowing）

即明确指出需要转换的类型，由程序员手动强制转换。

```java
double x = 100.04;
long y = (long) x;   // double → long（y=100，小数丢失）

int i = 200;
byte b = (byte) i;   // int → byte（b=-56，溢出）
```

显式转换可以通过在数值前加上「`(类型)`」来完成。显式转换由于是程序员自己决定的转换类型，所以 Java 编译器不会考虑是否有问题。显式转换有可能发生精度丢失或者数值溢出的情况。

## 2.5 关系运算符

另一类常见的 Java 运算符就是关系运算符。关系运算符用于比较两个值之间的关系，并返回一个布尔值（`true` 或 `false`）。其实，关系运算就是我们日常生活里的「比大小」。

| 运算符 | 名称 | 描述 | 示例 | 结果 |
|--------|------|------|------|------|
| `==` | 等于 | 检查两个值是否相等 | `5 == 5` | true |
| `!=` | 不等于 | 检查两个值是否不相等 | `5 != 3` | true |
| `>` | 大于 | 检查左值是否大于右值 | `10 > 5` | true |
| `<` | 小于 | 检查左值是否小于右值 | `10 < 5` | false |
| `>=` | 大于或等于 | 检查左值是否大于等于右值 | `10 >= 10` | true |
| `<=` | 小于或等于 | 检查左值是否小于等于右值 | `10 <= 5` | false |

```java
int a = 5;
int b = 6;
boolean c = a > b; // c = false
```

关于关系运算，务必要记住它<font color="red">**总是会返回布尔值**</font>，我们可以用一个新的变量（比如上述代码的 `c`）来接收这个结果。

此外，在 Java 中不是任意的两个类型都可以进行比较。

### 浮点数的比较

大多数情况下，应该尽量避免对两个浮点数进行等于或者不等于的比较。而对于初学者，应该完全避免对两个浮点数进行判等的比较。来看一个示例：

```java
float a = 0.1f; 
System.out.println(a == 0.1); // 结果是true还是false？
```

上述代码中变量 `a` 和 `0.1` 做相等判断，请问结果是 `true` 还是 `false`？看起来 `0.1f` 和 `0.1` 数值是相等的，所以结果应该是 `true`。但实际代码的运行结果是 <font color="orange">`false`</font>。那为什么会出现这种情况？

我们之前有讲过，在 Java 中，浮点数往往都是不精确的：

```java
float a = 0.1f; // 实际存储值：0.10000000149011612
```

这在和 `0.1`（实际上这是个 `double` 类型）进行比较时，自然会被认为是不相等的。

但实际上，在程序员看来 `0.1f` 和 `0.1` 就应该被判断为相等才符合我们的预期。那怎么解决这个问题？

Java 有很多方法来解决浮点数不能直接判等这个问题，比较常见的有以下几种方法：

- 使用误差范围。只要两个浮点数的差小于某个数值，即认为是相等的。
- 使用 <font color="blue">`BigDecimal`</font>（高精度计算）。
- 将浮点数转换成整数后再比较。

这里比较推荐第二种方法。

### BigDecimal 类型

在 Java 中，`BigDecimal` 类提供了高精度的十进制算术运算能力，特别适用于需要精确计算的金融、货币和科学计算场景。与浮点数不同，`BigDecimal` 可以精确表示和控制小数的精度和舍入行为。

为什么需要 `BigDecimal` 类型？这是因为浮点数具有局限性，比如我们反复谈到的不精确问题：

```java
System.out.println(0.1 + 0.2); // 0.30000000000000004
```

但是 `BigDecimal` 可以解决这个不精确的问题。

```java
BigDecimal a = new BigDecimal("0.1"); // 精确值
BigDecimal b = new BigDecimal("0.2");
```

这里需要注意，`BigDecimal` 并不属于基本数据类型，它其实是一个类，我们需要通过实例化来生成一个 `BigDecimal` 对象。同时，务必要注意，<font color="red">**在实例化时，我们不要直接传入数字，而应该传入一个字符串**</font>。下面是反例：

```java
// 会引入浮点误差
BigDecimal c = new BigDecimal(0.1); 
System.out.println(c); 
// 0.1000000000000000055511151231257827021181583404541015625
```

这主要是因为字符串表示数字是没有误差的，但是如果传入 `0.1` 这个浮点数本身就有误差，那么创建的 `BigDecimal` 自然也有误差。

当然，`BigDecimal` 虽然解决了精度误差，但其运行速度远比 `double`、`float` 等基本类型要慢。如非必要，尽量选择基本数据类型。

### 关系运算的自动类型提升

当不同类型进行比较时，Java 会自动进行类型提升：

```java
int i = 10;
double d = 10.0;
System.out.println(i == d); // true（int提升为double）
```

### 引用类型的比较

对于基本类型（`int`、`double`、`short` 等），`==` 和 `!=` 比较的是实际值，通常符合我们的预期。但是对于引用类型（对象或者字符串），`==` 和 `!=` 比较的是对象引用（内存地址），而不是内容。关于这一点，在后续探讨引用类型时我们再详细讲解。

### 布尔值比较

对于布尔值只能使用 `==` 和 `!=` 进行比较，不能使用 `>`、`<`、`>=`、`<=` 比较布尔值。

```java
boolean b1 = true;
boolean b2 = false;
System.out.println(b1 == b2); // false
System.out.println(b1 != b2); // true
```

## 2.6 表达式与语句

Java 代码由语句构成，而语句中可以包含表达式。语句与表达式的区别在于是否产生值。

### 表达式（Expression）

表达式是一种代码片段，它主要的目的是为了计算出一个值。表达式通常由变量、常量、运算符、方法调用等组成，最终会产生一个确定的值。它有以下两个特点：

- 必须返回一个值（如数字、布尔、字符串或对象等）
- 表达式不能单独使用，必须嵌入到语句中使用

直接看示例：

```java
5 + 3              // 算术表达式 → 值：8
a > b              // 布尔表达式 → 值：true/false
5 + (3 - 2)        // 先求表达式3-2，计算结果为1，然后再求5+1，最终表达式返回6
cat.age            // 访问对象属性也是表达式
"Hello".length()   // 方法调用也是一个表达式
3 + 2 + "Hello".length() // 多个表达式组成新的表达式
true && false || false   // 连续逻辑运算表达式
```

我们可以看到上述所有的表达式最终都会返回一个值，且多个表达式可以组合成一个新的表达式（比如，第 6 行）。

要特别注意，表达式不是一个完整的代码单元（即不能单独成为一行代码），它只是「片段」，所以表达式后面不能加 `;` 号。强行在表达式后面加 `;` 号会导致程序错误：

```java
5 + 3; // 加了分号，导致Java报错，表达式不能单独成为一行代码。
```

在 Java 中，只有语句才可以单独成为一行代码。

大多数情况下，表达式都会被嵌入到一个完整的语句中，比如：

```java
int a = 5 + 3; // 表达式被嵌入到赋值语句中
if (true && false || false) {
  // 表达式被嵌入到条件语句中
}
```

务必记住，表达式最重要的作用是计算出一个值，但表达式不能单独作为一行语句。

### 语句（Statement）

Java 中的可执行单元是「语句」（表达式不能被单独执行）。

语句执行后不产生值（或返回值被忽略，见下小节「表达式语句」），这是它与表达式最大的不同。它通常以分号 `;` 或代码块 `{}` 结束：

```java
int x = 10;           // 赋值语句。
System.out.println("Hi"); // 方法调用语句
final double PI = 3.14; // 常量声明语句
```

还有一些我们还未学习到的语句，比如流程控制语句（Control Flow Statements），如条件、循环语句：

```java
if (a > b) { ... }      // 条件语句，以{}结尾
for (int i = 0; i < 10; i++) { ... } // 循环语句，以{}结尾
```

切记，语句必须以分号 `;` 或者 `{}` 来结尾，否则 Java 会报错：

```java
final double PI = 3.14 // 缺少分号结尾，会报错
```

总结下，语句通常有以下三类：

**1. 表达式语句（Expression Statements）**

某些表达式加上分号后可作为语句使用（见下个小节）。

**2. 声明语句（Declaration Statements）**

用于声明变量或类。

```java
int x = 10;
String name;
```

**3. 控制流语句（Control Flow Statements）**

用于控制程序执行顺序，后续章节会学习：

- 条件语句：`if`、`switch`
- 循环语句：`for`、`while`、`do-while`
- 跳转语句：`break`、`continue`、`return`、`throw`

### 表达式语句 (Expression Statement)

在 Java 中，部分表达式可以在后面加上 `;` 号，这种语句是特殊的语句，我们称为「表达式语句」，最典型的表达式语句是在方法调用后加上 `;` 号：

```java
"Hello".length(); // "Hello".length是表达式(不加分号)，但加分号后成为表达式语句
```

不是所有的表达式都可以加 `;` 号成为表达式语句，只有以下几种表达式可以成为表达式语句：

| 表达式类型 | 示例 | 说明 |
|-----------|------|------|
| 自增/自减 | `i++;` `--count;` | 修改变量值，后续章节讲解 |
| 方法调用 | `System.out.println("Hi");` `list.add(item);` | 无论方法是否有返回值，方法调用都是表达式语句 |
| 对象创建 | `new Thread(r).start();` | `new` 表达式语句通常需要配合方法调用才有意义，比如这里调用了 `start` 方法。单纯的 `new Thread();` 可以，但没有意义。 |

| 一元运算符 | Unary Operator | /ˈjuːnəri ˈɒpəreɪtə(r)/ | 只需一个操作数的运算符，如 `++`、`--`、`!` |
| 二元运算符 | Binary Operator | /ˈbaɪnəri ˈɒpəreɪtə(r)/ | 需要两个操作数的运算符，如 `+`、`-`、`*`、`/` |
| 三元运算符 | Ternary Operator | /ˈtɜːnəri ˈɒpəreɪtə(r)/ | 需要三个操作数的运算符，Java 中仅 `?:` 一个 |
